# AI Literacy 학습 정리

## 1. AI Literacy?
AI Literacy는 **인공지능(AI)을 이해하고, 올바르게 활용할 수 있는 능력**입니다.

- AI가 무엇인지 이해하기
- AI가 어떻게 동작하는지 이해하기
- AI의 결과를 비판적으로 판단하기
- AI를 올바르게 활용하기
등의 능력을 포함합니다.

## 2. 인공지능(AI)?

AI(Artificial Interlligence)는 인간의 지능적인 능력을 컴퓨터가 수행하도록 만드는 기술입니다.
인간이 할 수 있는 이미지, 음성 인식, 언어 이해, 문제 해결, 예측, 추천 등의 작업을 컴퓨터가 수행하도록 합니다.
인공지능(AI) → 데이터 학습 → 패턴 발견 → 새로운 데이터 예측 또는 판단

## 3. AI의 발전 과정 
AI → 머신러닝 → 딥러닝 → 생성형 AI → LLM → ChatGPT 같은 모델 
여기서 생성형 AI는 딥러닝을 기반으로 하는 AI 응용 분야라고도 볼 수 있습니다. 

## 4. 머신러닝(Machine Learning): 머신러닝은 데이터를 통해 규칙을 학습하는 기술입니다.
기존 프로그래밍은 사람이 직접 규칙을 작성하지만 머신러닝은 데이터를 이용하여 규칙을 학습합니다. 
생성된 모델은 새로운 데이터를 예측 할 수 있습니다.

## 5. 딥러닝(Deep Learning): 딥러닝은 머신러닝의 한 분야입니다.
인공신경망(Neural Network)을 여러 층으로 구성하여 복잡한 데이터를 학습합니다. 
입력층 → 은닉층 → 은닉층 → 출력층
이미지 분류, 음성 인식, 자연어 처리, 자율주행, 추천시스템 등 같은 분야에서 사용됩니다. 

## 6. 생성형 AI(Generative AI): 생성형 AI는 새로운 콘텐츠를 만들어내는 AI입니다.
텍스트 생성, 이미지 생성, 음악생성, 영상 생성, 코드 생성 등 사용자의 입력을 기반으로 새로운 결과를 생성합니다. 

## 7. LLM?: LLM은 Large Language Model의 약자, 대규모 언어 모델
많은 양의 텍스트 데이터를 학습하여 인간의 언어를 이해하고 생성할 수 있습니다. 
덱스트 데이터 → LLM 학습 → 언어 패턴 학습 → 새로운 문장 생성
질문 답변, 문서 요약, 번역, 코드 작성, 글 작성, 정보 정리 등 같은 작업을 수행할 수 있습니다. 

## 8. 학습데이터와 테스트 데이터 
Train Data → 모델을 학습시키는 데이터
Test Data → 학습이 끝난 모델의 성능을 확인하는 데이터 

## 9. 프롬프트(Prompt)?: 프롬프트는 AI에게 전달하는 명령 또는 질문입니다.
구체적으로 요청하는 것이 중요하다.
좋은 프롬프트 에는 역할, 목적, 조건, 출력 형식 등 같은 요소를 포함해야 한다. 

## 10. AI Hallucination: AI가 실제 사실이 아닌 내용을 그럴듯하게 생성하는 현상
존재하지 않는 정보를 사실처럼 말할 수 있습니다. 
따라서 AI의 답변은 검증하는 과정이 필요합니다. 

# 🎯 AI Literacy 핵심 정리
| 개념               | 설명                        |
| ---------------- | ------------------------- |
| AI               | 인간의 지능적인 작업을 수행하는 기술      |
| Machine Learning | 데이터를 통해 규칙을 학습            |
| Deep Learning    | 여러 층의 신경망을 이용한 학습         |
| Generative AI    | 새로운 콘텐츠 생성                |
| LLM              | 대량의 텍스트를 학습한 언어 모델        |
| Prompt           | AI에게 전달하는 명령 또는 질문        |
| Hallucination    | AI가 잘못된 정보를 그럴듯하게 생성하는 현상 |

## 💡 한 줄 정리
AI Literacy란 AI가 무엇인지 이해하고, 올바른 프롬프트를 사용하며, AI의 결과를 비판적으로 판단하고 활용하는 능력이다.
