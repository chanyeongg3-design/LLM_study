## 2. Dropout
### 2-1. Dropout 이란?
Dropout은 학습 중 일부 뉴런의 출력을 무작위로 0으로 만드는 기법이다. 
모델이 특정 뉴런에만 의존하지 못하게 하여 여러 뉴런이 함께 특징을 학습하도록 만든다.
특정 뉴련에 지나치게 의존
→ 일부 뉴런을 무작위로 끔
→ 다른 뉴런도 역할을 분담
→ 과적합 완화
### 2-2. Dropout의 p
`nn.Dropout(p=0.3)` 
p=0.3은 뉴런 출력을 30% 확률로 0으로 만든다는 뜻이다. 

비율이 지나치게 크면 정보가 너무 많이 사라져 Underfitting이 발생할 수 있다.
### 2-3. Train과 Eval 차이
```Python
import torch
import torch.nn as nn

torch.manual_seed(0)

dropout = nn.Dropout(p=0.5)
x = torch.ones(10)

# 학습 모드: 일부 값이 무작위로 0이 됨
dropout.train()
train_output = dropout(x)

# 평가 모드: Dropout이 꺼짐
dropout.eval()
eval_output = dropout(x)

print("train:", train_output)
print("eval:", eval_output)
```

> 검증이나 추론 전에 model.eval( )을 호출하지 않으면 예측 결과가 계속 달라질 수 있다. 
## 3. BatchNorm
### 3-1. BatchNorm이란?
BatchNorm은 Layer의 중간 출력인 Activation의 분포를 안정화하는 기법이다
```Plain Text
Linear 또는 Conv 출력
→ BatchNorm
→ ReLU
→ 다음 Layer
```
주요 효과:
- Activation이 지나치게 크거나 작아지는 현상 완화
- 더 빠른 수렴 가능
- 약한 Regularization 효과
### 3-2. BatchNorm 종류

```Plain Text
self.fc1 = nn.Linear(784, 128)

# 128은 Batch Size가 아니라 fc1의 출력 feature 수
self.bn1 = nn.BatchNorm1d(128)
```
### 3-3. Dropout과 함께 적용하기 
```Python
import torch.nn as nn

class StableMLP(nn.Module):
		def __init__(self, num_classes=10):
				super().__init__()
				
				self.flatten = nn.Flatten()
				
				self.block = nn.Sequential(
						nn.Linear(784,128),   # 784 -> 128
						nn.BatchNorm1d(128),  # Feature 분포 안정화
						nn.ReLU(),            # 비선형성 추가
						nn.Dropout(p=0.3),    # 과적합 완화
 				)
				
				self.classifier = nn.Linear(128, num_classes)
		
		
		def forward(self, x):
				x = self.flatten(x)
				x = self.block(x)
				
				# Softmax 이전의 Logits 반환 
				return self.classifier(x)

```
> 일반적인 순서 : Linear → BatchNorm → ReLU → Dropout

## 4. Early Stopping
### 4-1. Early Stopping이란?
Early Stopping은 Validation 성능이 일정 기간 개선되지 않으면 학습을 중단하는 방법이다. 
```Python
Epoch 학습
-> validation Loss 계산
-> 이전 Best보다 좋아졌는지 확인
-> 좋아졌으면 Best Model 저장
-> 오랫동안 개선되지 않으면 중단
```
Train Loss는 계속 낮아져도 Validation Loss는 다시 높아질 수있다. 
초반: Train Loss ↓, Validation Loss ↓
중반: Validation Loss 최저점
후반: Train Loss ↓, Validation Loss ↑
### 4-2. patience와 min_delta

예를 들어 patience=3, min_delta=0.001이면 Validation Loss가 0.001 이상 낮아지는 개선이 3 Epoch 연속 없을 때 중단한다. 
### 4-3. EarlyStopping 핵심 코드
```Python
import math

class EarlyStopping:
		def __init__(self, patience=3, min_delta=0.0):
		
				# 검증 손실이 개선되지 않아도 기다릴 epoch 횟수
				self.patience = patience
				# 손실이 최소한 얼마나 감소해야 개선으로 인정할지 설정
				self.min_delta = float(min_delta)
				
				# 지금까지 가장 낮았던 검증 손실
				# 아직 검증하지 않았으므로 None으로 초기화
				self.best_loss = None
			
				# 검증 손실이 연속으로 개선되지 않은 횟수 
				self.counter = 0
				
				# 학습 중단 여부 
				self.should_stop = False
				
		def step(self, valid_loss):
				# Tensor나 정수로 전달되더라도 비교할 수 있도록 실수로 변환
				valid_loss = float(valid_loss)
				
				# valid_loss가 NaN 또는 무한대인지 확인
				if not math.isfinite(valid_loss):
						raise ValueError("valid_loss가 NaN 또는 inf입니다.")
				
				# 첫 번째 검증인 경우 비교 대상이 없으므로
				# 현재 검증 손실을 best_loss로 저장
				if self.best_loss is None:
						self.best_loss = valid_loss
						
						# 학습 중단 여부: False
						# 손실 개선 여부: True
						return False, True
				
				# 이전 최고 손실에서 현재 손실을 빼서
				# 손실이 얼마나 감소했는지 계산
				improvement = self.best_loss - valid_loss
				
				# 손실이 실제로 감소했고, 감소량이 min_delta 이상인지 확인
				improved = (
						improvement > 0.0
						and improvement >= self.min_delta
				)
				
				if improved:
						# 손실이 개선되었으면 최고 기록 갱신
						self.best_loss = valid_loss
						
						# 연속 미개선 횟수 초기화
						self.counter = 0
				else:
						# 손실이 개선되지 않았으면 카운터 증가
						self.counter += 1
				# 미개선 횟수가 patience 이상이면 학습 중단
				self.should_stop = self.counter >= self.patience
				
				# 학습 중단 여부와 이번 epoch의 개선 여부 반
				return self.should_stop, improved
```

```Python
import torch

# HWC 형태

print(chw_image.shape) # (3, 32, 32)
```

## 6. Convolution, Kernel, Filter
### 6-1. Convolution 이란?
convolution은 작은 Filter를 이미지 전체에 반복 적용하여 지역 패턴을 찾는 연산이다
- Kernel, Filter: 패턴을 검사하는 작은 Weight
- Feature Map: Filter의 반응 결과
- 국소 연결: 이미지의 작은 영역을 확인
- 가중치 공유: 같은 Filter를 모든 위치에서 반복 사용
```Plain Text
입력 이미지 
-> Convolution
-> Feature Map
-> ReLU
-> Poling
```
### 6-2. Conv2d 핵심 인자
```Plain Text
conv = nn.Conv2d(
		in_channels=3,
		out_channels=8,
		kernel_size=3,
		padding=1,
		stride=1
)
```

### 6-3. Conv2d Shape
```Python
import torch
import torch.nn as nn

x = torch.randn(4, 3, 32, 32)

conv = nn.Conv2d(
		in_channels=3,

```

Conv2d Weight Shape: (out_channels, in_channels, kernel_height, kernel_width)
out_channels는 Class 수가 아니라 **Feature Map 수**다. 
## 7. Padding과 Stirde
### 7-1. Padding
Padding은 입력 이미지 가장자리에 값을 추가하는 것이다. 
- 가장자리 정보 손실 완화
- 출력 H·W 크기 조절
- 여러 Conv Layer를 쌓을 때 크기 유지 
```Python
x = torch.randn(1, 3, 32, 32)
# Padding 없음
conv1 = nn.Conv2d(3, 8, kernel_size=3, padding=0)

# Padding 1
conv2 = nn.Conv2d(3, 8, kernel_size=3. padding=1)

print(conv1(x).shape) # (1, 8, 30, 30)
print(conv2(x).shape) # (1, 8, 32, 32)
```
### 7-2. Stride
Stride는 Kernel이 한 번에 이동하는 칸 수다. 
stride=1 : 한 칸씩 이동
stride=2 : 두 칸씩 이동
```Python
conv = nn.Conv2d(
		3,
		8,
		kernel_size=3,
		padding=1,
		stride=2
)

y = conv(torch.randn(1, 3, 32, 32))
print(y.shape) # (1, 8, 16, 16)
```
### 7-3. 출력 크기 공식
Dilation이 1일 때:
```Python
H_out = floor((H_in + 2P - K) / S + 1)
W_out = floor((W_in + 2P - K_ / S + 1)
```

Padding을 넣는다고 무조건 크기가 유지되는 것은 아니다. 
## 8.  Pooling
Max Pooling은 작은 영역에서 가장 큰 값을 남겨 Feature Map의 공간 크기를 줄인다.
```Python
import torch
import torch.nn as nn

x = torch.randn(8, 16, 32, 32)

pool = nn.MaxPool2d(kernel_size=2)
y = pool(x)

print(y.shape) # (8, 16, 16, 16)
```
Batch Size: 8 유지
Channel: 16 유지
Height: 32 → 16
Width: 32 → 16
> MaxPool2d(2)는 기본적으로 stride=2를 사용한다. 
## 9. Feature Map과 Flatten
```Plain Text
입력
(N, 3, 32, 32)

Conv2d(3 → 16)
(N, 16, 32, 32)

MaxPool2d(2)
(N, 16, 16, 16)

Conv2d(16 → 32)
(N, 32, 16, 16)

MaxPool2d(2)
(N, 32, 8, 8)

Flatten
(N, 2048)

Flatten Feature 수:
32 x 8 x 8 = 2048

Batch 차원을 유지하려면 다음과 같이 사용한다

flat = torch.flatten(feature_map, start_dim=1)
```
- start_dim=1: Batch 차원 유지
- C, H, W만 한 줄로 펼침
## 10. CNN Classifier 전체 코드
```Python
import torch
import torch.nn as nn

class SimpleCNN(nn.Module):
		def __init__(self. num_classes=10):
				super().__init__()
				
				# 이미지에서 공간적 특징을 추출 
				self.features = nn.Sequential(
						# (N, 3, 32, 32) -> (N, 16, 32, 32)
						nn.Conv2d(
								in_channels=3,
								out_channels=16,
								kernel_size=3,
								padding=1
						),
						nn.ReLU(),
						
						# (N, 16, 32, 32) -> (N, 16, 16, 16)
						nn.MaxPool2d(2),
						# (N, 16, 32, 32) -> (N, 32, 16, 16)
						nn.Conv2d(
								in_channels=16,
								out_channels=32,
								kernel_size=3,
								padding=1
						),
						nn.ReLU(),
						# (N, 32, 16, 16) -> (N, 32, 8, 8)
						nn.MaxPool2d(2)
				)
				
				# C, H, W를 한 줄로 펼침
				self.flatten = nn.Flatten()
				# 32 x 8 x 8 = 2048
				self.classifier = nn.Linear(
						in_features=32 * 8 * 8,
						out_features=num_classes
				)
				
		def forward(self, x):
				# 공간적 특징 추출 
				x = self.features(x)
				# (N, 32, 8, 8) -> (N, 2048)
				x = self.flatten(x)
				# (N, 2048) → (N, num_classes)
				logits = self.classifier(x)
				
				return logits
				
	model = SimpleCNN(num_classes=10)
	# 8장의 RGB 32×32 이미지
	images = torch.randn(8, 3, 32, 32)
	# Forward
	logits = model(images)
	
	print("images shape:", images.shape)
	print("logits shape:", logits.shape)
	
	assert logits.shape == torch.size([8, 10])
```
최종 출력은 (batch_size, num_classes) 형태다
CrossEntropyLoss를 사용 할 때는 Softmax를 미리 적용하지 않는다.
