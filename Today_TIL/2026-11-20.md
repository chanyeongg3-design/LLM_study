# **주제: LoRA 어댑터 학습, 저장·복원, 전체 SFT와 비교**

오늘 자료에서는 기존 모델의 가중치를 그대로 둔 채 작은 추가 가중치만 학습하는 LoRA를 살펴봤다. 아래 결과는 **교안의 실험 결과**이며, 실제로 어디까지 직접 실행했는지는 확인되지 않았다.

## 1. LoRA의 핵심 원리
LoRA는 기존 가중치 `W`를 고정하고, 작은 행렬 `A`, `B`를 통해 학습한 변화량을 더하는 방식이다.

1. LoRA는 어디를 학습할까?
기존 모델의 가중치 w는 고정하고, 옆에 붙인 작은 행렬 A, B 만 학습한다. 마지막에는 기존 출력과 LoRA가 만든 변화량을 더한다.

<img width="1762" height="378" alt="mermaid-diagram (20)" src="https://github.com/user-attachments/assets/a6729502-b6b7-4919-830a-15f919e33a64" />


```python
h = W @ x + (alpha / r) * B @ A @ x
```

- `W @ x`: 기존 모델이 만드는 출력
- `B @ A @ x`: LoRA가 학습해 추가하는 변화량
- `r`: 작은 행렬 사이의 중간 크기인 랭크
- `alpha / r`: 변화량에 곱하는 배율

교안의 설정은 `r = 8`, `alpha = 16`이므로 배율 2다. 

기존 가중치와 변화량을 따로 계산한 결과는, 변화량을 기존 가중치에 합친 뒤 계산한 결과와 같다. 이 원리를 이용해 학습한 어댑터를 모델에 병할할 수 있다. 

### 학습 파라미터 수

|구분|파라미터 수|
|---|--:|
|기존 기반 모델|494,032,768|
|LoRA 추가 파라미터|540,672|
|LoRA를 붙인 전체 파라미터|494,573,440|
|학습 대상 비율|0.1093%|

**전체 모델을 학습하지 않고 `540,672`개만 학습하므로, 기울기와 옵티마이저 상태를 저장하는 데 필요한 메모리가 줄어든다.**

## 2. LoRA와 SFT, PEFT의 관계

|    용어    | 역할                               |
| :------: | :------------------------------- |
| **SFT**  | 모범답안을 이용해 모델을 학습시키는 목표           |
| **LoRA** | 어떤 파라미터를 학습할지 정하는 방법             |
| **PEFT** | LoRA처럼 일부 파라미터만 학습하는 구성을 적용하는 도구 |

즉, **SFT를 수행할 때 LoRA를 학습 방법으로 사용할 수 있다.**

교안에서는 `LoraConfig`로 설정을 지정하고, `get_peft_model()`로 기반 모델에 LoRA를 붙인다. **`get_peft_model()`은 어댑터를 붙이는 함수이며, 호출만으로 학습이 끝나는 것은 아니다.**

```
LoraConfig(    r=8,    lora_alpha=16,    target_modules=["q_proj", "v_proj"],    lora_dropout=0.0,    bias="none",)
```

또한 기본 초기화에서는 `B = 0`으로 시작해 **처음 출력이 기존 모델과 같다.** 교안의 예제에서는 첫 번째 갱신 때 `B`가 먼저 바뀌고, 이후 `A`도 학습된다.

## 3. 어댑터 저장과 복원

LoRA에서는 전체 기반 모델을 다시 저장하지 않고 **학습한 어댑터와 설정만 따로 저장**할 수 있다.

|작업|함수|의미|
|---|---|---|
|저장|`model.save_pretrained()`|어댑터 가중치와 설정 저장|
|복원|`PeftModel.from_pretrained()`|같은 기반 모델에 어댑터 연결|
|병합|`merge_and_unload()`|LoRA 변화량을 기존 가중치에 합침|

교안의 어댑터 크기는 **2.1MB**, 가중치 파일은 **2175168 bytes**다.

복원 실험에서는 **logits 최대 절대 오차 `0.0`**, 생성 응답 일치 여부는 **`True`**였다. 복원할 때는 **기반 모델 ID와 revision을 맞추고, dtype도 확인해야 한다.**

## 4. 전체 SFT와 LoRA 비교

교안에서는 데이터, 학습 횟수, 학습률 등 주요 조건을 맞추고 비교했다.

|항목|baseline|전체 SFT|LoRA|
|---|--:|--:|--:|
|학습 파라미터|0|494,032,768|540,672|
|dev loss|0.9207|0.0049|0.8717|
|형식 통과|0/12|12/12|0/12|
|학습 시간|-|27초|19초|
|최대 메모리|-|4.66GiB|1.61GiB|

이 실험에서 LoRA는 메모리를 적게 사용했지만, 같은 학습률 `2e-5`에서는 **dev loss가 `0.9207 → 0.8717`로 줄었어도 형식 통과는 `0/12`**였다. 교안의 관찰 문항에서는 학습 전후 답변도 글자까지 같았다.

**핵심: loss가 줄었다고 해서 모델의 실제 답변이 원하는 방향으로 바뀌었다고 단정할 수 없다. 생성된 답변 원문도 함께 확인해야 한다.**

## 5. 설정 변경 후 결과

|실행|학습 파라미터|dev loss|형식|판단|시간|메모리|
|---|--:|--:|--:|--:|--:|--:|
|전체 SFT (`lr 2e-5`)|494,032,768|0.0049|12/12|10/12|27초|4.66GiB|
|원본 LoRA (`2e-5 · q·v`)|540,672|0.8717|0/12|0/12|19초|1.61GiB|
|LoRA (`2e-4 · q·v`)|540,672|0.4411|12/12|6/12|18초|1.61GiB|
|LoRA (`2e-4 · all-linear`)|4,399,104|0.0184|12/12|10/12|27초|1.67GiB|

**형식 통과와 판단 정확성은 서로 다르다.** 예를 들어 `2e-4 · q·v`는 형식에서 `12/12`였지만, 판단은 `6/12`였다.

또한 `2e-4 · all-linear`는 이 실험에서 전체 SFT와 같은 판단 점수인 `10/12`를 기록했다. 다만 **seed 42, dev 12, 1회 실행** 결과이므로, 이를 모든 데이터와 설정에 일반화할 수는 없다.

**오늘의 핵심:** LoRA는 **적은 파라미터와 메모리로 학습할 수 있는 방법**이다. 다만 좋은 결과를 얻으려면 학습률과 적용할 층을 살펴보고, **loss·출력 형식·실제 판단을 함께 평가**해야 한다.
