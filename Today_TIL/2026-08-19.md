## 2장. 핵심 개념
### 1. Tensor
Tensor는 딥러닝에서  숫자 데이터를 담는 기본 자료구조
이미지 → 숫자 → Tensor
텍스트 → 숫자 → Tensor
Label → 숫자 → Tensor
### 1-1. Tensor의 핵심 정보
shape → 모양 | print(x.shape)
ndim → 차원 수 
dtype → 자료형 | print(x.dtype) 
device → CPU/GPU | print(x.device)
### 1-2. Tensor 차원
0차원 → Scaler → 숫자 하나
1차원 → Vector →  [3]
2차원 → Matrix → [2, 3]
3차원 → 여러 Matrix
### 1-3. Tensor 생성
torch.tensor() → 직접 값 입력
torch.zeros() → 0으로 채움
torch.ones() → 1로 채움
torch.randn() → 랜덤 실수 생성
## 2. Batch
여러 샘플을 한 번에 처리하는 단위
샘플 1개 → [feature]
여러 샘플 → [batch, channel, height, width]
## 3. unsqueeze / squeeze
unsqueeze → 차원 추가 [4] →(unsqueeze(0)) → [1, 4]
squeeze → 크기가 1인 차원 제거 [1, 4] →(squeeze(0)) → [4]
## 4. Broadcasting
서로 다른 shape의 Tensor를 조건에 맞게 자동으로 맞춰 연산하는 기능: 오른쪽부터 비교
주의: 잘못 계산하면 결과가 잘못나올수도 있다, 그래서 Loss 계산 전
print(pred.shape)
print(target.shape)
를 확인한다.

## 2. ❓ 왜 필요한가?
### Q1. Tensor가 왜 필요한가?
딥러닝 모델은 결국 숫자로 입력받아 숫자를 출력한다.
이미지 → 숫자
텍스트 → 숫자
정답 label → 숫자
PyTorch에서는 이런 숫자 데이터를 담는 기본 구조가 Tensor이다.
Tensor → 딥러닝에서 사용하는 숫자 상자
### Q2. 왜 shape를 확인해야 하는가?
딥러닝에서는 데이터의 모양이 맞아야 연산할 수 있기 때문이다. 
Ex) [4] 와 [4, 1]은 값의 개수는 같아 보여도 서로 다른 shape이다.
특히 batch가 들어가면 
샘플 1개 → [4]
샘플 4개 → [4, 4] 
처럼 차원의 의미가 달라진다. 
### Q3. 왜 dtype을 확인해야 하는가?
Loss 함수나 모델이 요구하는 자료형과 실제 Tensor의 dtype이 다르면 오류가 발생할 수 있기 때문이다.
CrossEntropyLoss
→ class index target은 torch.long
BCEWithLogitsLoss
→ 0/1 target은 보통 float Tensor
모델 입력
→ 일반적으로 float32
따라서 Tensor을 볼 때는 X.shape, X.dtype, X.device를 함께 확인하는 습관이 중요
### Q4. 왜 Batch dimension이 필요한가?
딥러닝에서는 데이터를 하나씩 처리하기보다 여러 개를 묶어서 처리하는 것이 일반적이기 때문이다.
학생 1명
→ [4]
학생 3명
→ [3, 4]
여기서 
3 → batch size
4 → fearture 수 
### Q5. 왜 unsqueeze( )가 필요한가?
샘플 하나의 Shape가 [4] 인데 모델이 [batch_size, feature] 형태를 기대할 수 있다.
이때 sample.unsqueeze(0)을 사용하면 [4] → [1, 4]가 된다.
즉, 샘플 하나를 batch 1개짜리 형태로 바꾸는 것이다.
### Q6. 왜 Broadcasting을 알아야 하는가?
PyTorch는 Shape가 조금 달라도 조건이 맞으면 자동으로 크기를 맞춰 연산한다.
이것이 Broadcasting 이다
편리하지만 잘못 사용하면 원하지 않는 shape으로 계산될 수있다.

## 3. 용어 정리
- Tensor → 딥러닝에서 숫자를 담는 기본 자료구조
- Scaler → 0차원 Tensor, 숫자 하나
- Vector → 1차원 Tensor
- Matrix → 2차원 Tensor
- Shape → Tensor의 구조/크기
- ndim → Tensor의 차원 수
- dtype → Tensor 내부 숫자의 자료형
- device → Tensor가 저장된 CPU/GPU 위치
- Batch → 여러 샘플을 묶은 단위
- Batch dimension → 여러 샘플을 구분하는 차원
- Feature → 하나의 샘플을 설명하는 입력 값
- unsqueeze( ) → 차원을 추가
- squeeze ( ) → 크기가 1인 차원을 제거
- Broadcasting → 서로 다른 shape을 자동으로 맞춰 연산하는 규칙
- **long** → 정수형 dtype, 주로 class index에 사용 ,  **float 32** → 실수형 dtype, 모델 입력 등에 자주 사용
- Logit → Sigmoid/Softmax 적용 전의 원시 출력값
- Parameter → 학습하면서 변경되는 weight, bias 등의 값
- Gradient → Parameter를 어느 방향으로 변경할지 알려주는 값
- Backward → Gradient를 계산하는 과정
- Optimizer → Gradient를 이용해 Parameter를 업데이트하는 도구
