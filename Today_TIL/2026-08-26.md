## 1. Transform으로 데이터 전처리하기
실제 데이터는 모델에 바로 넣기 어려운 경우가 많다.
이미지 데이터라면 보통 다음 과정을 거친다.
```Plain Text
원본 이미지
↓
Resize
↓
ToTensor
↓
Normalize
↓
모델 입력 Tensor
```
대표적인 Transform은 다음과 같다.

```Python
from torchvision import transforms

# Train 데이터에 적용할 전처리
train_transform = transforms.Compose([
    # 이미지 크기를 128x128로 통일
    transforms.Resize((128, 128)),

    # 학습 데이터에만 50% 확률로 좌우 반전
    # 같은 이미지를 조금씩 다르게 보여주기 위한 Data Augmentation
    transforms.RandomHorizontalFlip(p=0.5),

    # 이미지를 PyTorch Tensor로 변환
    transforms.ToTensor(),

    # RGB 3개 채널의 값을 정규화
    transforms.Normalize(
        mean=(0.5, 0.5, 0.5),
        std=(0.5, 0.5, 0.5)
    )
])

# Validation 데이터에 적용할 전처리
valid_transform = transforms.Compose([
    # Train과 동일한 크기로 맞춤
    transforms.Resize((128, 128)),

    # Tensor로 변환
    transforms.ToTensor(),

    # Train과 동일한 기준으로 정규화
    transforms.Normalize(
        mean=(0.5, 0.5, 0.5),
        std=(0.5, 0.5, 0.5)
    )
])
```
Train에는 랜덤한 Data Augmentation을 사용할 수 있지만, Valid/Test에서는 일관된 평가를 위해 보통 랜덤 Transform을 사용하지 않는다.

## 3. Normalize
Normalize는 다음 공식을 사용한다.
```Plain Text
정규화된 값 = (원래 값 - mean) / std
```
```Python
import torch

# 예제 입력 값
x = torch.tensor([0.0, 0.5, 1.0])

# 정규화에 사용할 평균과 표준편차
mean = 0.5
std = 0.5

# Normalize 공식 직접 계산
x_norm = (x - mean) / std

print(x_norm)
```
출력:
```Plain Text
tensor([-1., 0., 1.])
```
입력 값의 Scale을 일정하게 조정하면 모델 학습을 안정적으로 만드는 데 도움을 줄 수 있다.

## 4. Custom Dataset에서 Transform 적용
Custom Dataset에서는 보통 `**getitem**()` 안에서 Transform을 적용한다.
```Python
from torch.utils.data import Dataset

class DummyDataset(Dataset):

    def __init__(self, images, labels, transform=None):
        # 원본 이미지 저장
        self.images = images

        # 정답 Label 저장
        self.labels = labels

        # 사용할 Transform 저장
        self.transform = transform

    def __len__(self):
        # Dataset의 전체 Sample 수 반환
        return len(self.images)

    def __getitem__(self, idx):
        # idx번째 이미지와 Label 가져오기
        image = self.images[idx]
        label = self.labels[idx]

        # Transform이 지정되어 있으면 이미지에 적용
        if self.transform is not None:
            image = self.transform(image)

        # 전처리된 이미지와 정답 반환
        return image, label
```
핵심 차이는 다음과 같다.
```Plain Text
Dataset
→ 데이터를 어떻게 꺼낼지 정의

Transform
→ 꺼낸 데이터를 어떻게 바꿀지 정의
```

## 5. Train / Valid / Test Split
모델의 실제 성능을 평가하려면 데이터를 역할별로 나누어야 한다.
```Plain Text
Train
→ Parameter 학습

Validation
→ 모델 / Hyperparameter 선택

Test
→ 최종 성능 평가
```
쉽게 기억하면 다음과 같다.
```Plain Text
Train = 문제집
Valid = 모의고사
Test = 최종 시험
```
```Python
import torch
from torch.utils.data import TensorDataset, random_split

# Sample 100개, Feature 6개
X = torch.randn(100, 6)

# 0~2 사이의 Class Label 생성
# CrossEntropyLoss를 사용할 것이므로 dtype은 long
y = torch.randint(
    0,
    3,
    size=(100,),
    dtype=torch.long
)

# X와 y를 하나의 Dataset으로 묶음
dataset = TensorDataset(X, y)

# 같은 Split 결과를 다시 만들 수 있도록 Seed 고정
generator = torch.Generator().manual_seed(42)

# Train 70 / Valid 15 / Test 15로 분리
train_dataset, valid_dataset, test_dataset = random_split(
    dataset,
    [70, 15, 15],
    generator=generator
)
```
같은 Seed를 사용하면 같은 Random Split 결과를 재현할 수 있다.

## 6. Wrapper와 Split별 Transform
`random_split()`으로 만들어진 `Subset`들은 같은 원본 Dataset을 공유한다.
그래서 Train과 Valid에 서로 다른 Transform을 독립적으로 적용하려면 Wrapper Dataset을 사용할 수 있다.
```Plain Text
기존 Dataset
↓
Wrapper
↓
추가 Transform 적용
```
```Python
from torch.utils.data import Dataset

class SubsetWithTransform(Dataset):

    def __init__(self, base_dataset, indices, transform=None):
        # 원본 Dataset 저장
        self.base_dataset = base_dataset

        # 현재 Split에서 사용할 Index 저장
        self.indices = list(indices)

        # 현재 Split 전용 Transform 저장
        self.transform = transform

    def __len__(self):
        # 현재 Subset의 Sample 수 반환
        return len(self.indices)

    def __getitem__(self, idx):
        # Subset의 idx를 원본 Dataset의 실제 Index로 변환
        real_idx = self.indices[idx]

        # 원본 Dataset에서 Sample 가져오기
        x, y = self.base_dataset[real_idx]

        # 현재 Split 전용 Transform 적용
        if self.transform is not None:
            x = self.transform(x)

        return x, y
```
Wrapper는 **기존 객체를 없애는 것이 아니라 감싸서 기능을 추가하는 객체**라고 이해하면 된다.

## 7. DataLoader
Split된 Dataset은 DataLoader를 통해 Batch 단위로 모델에 공급된다.
```Python
from torch.utils.data import DataLoader

# Train 데이터는 Epoch마다 순서를 섞음
train_loader = DataLoader(
    train_dataset,
    batch_size=16,
    shuffle=True
)

# Validation은 평가 목적이므로 일반적으로 섞지 않음
valid_loader = DataLoader(
    valid_dataset,
    batch_size=16,
    shuffle=False
)

# Test 역시 순서를 섞을 필요가 없음
test_loader = DataLoader(
    test_dataset,
    batch_size=16,
    shuffle=False
)
```
일반적인 설정:
```Plain Text
Train  → shuffle=True
Valid  → shuffle=False
Test   → shuffle=False
```
`batch_size=16`은 전체 데이터가 16개라는 뜻이 아니라 **한 번에 16개의 Sample을 처리한다는 뜻**이다.

## 9. `nn.Module`과 `forward`
PyTorch 모델은 보통 `nn.Module`을 상속해서 작성한다.
```Plain Text
__init__()
→ 사용할 Layer 준비

forward()
→ 입력 데이터가 Layer를 통과하는 순서 정의
```
```Python
import torch.nn as nn

class SimpleMLP(nn.Module):

    def __init__(self, input_dim=4, hidden_dim=32, num_classes=3):
        # nn.Module의 기본 기능 초기화
        super().__init__()

        # 입력 Feature를 Hidden Feature로 변환
        self.fc1 = nn.Linear(
            input_dim,
            hidden_dim
        )

        # 비선형성을 추가하는 활성화 함수
        self.relu = nn.ReLU()

        # Hidden Feature를 Class별 점수로 변환
        self.fc2 = nn.Linear(
            hidden_dim,
            num_classes
        )

    def forward(self, x):
        # 첫 번째 Linear Layer 통과
        x = self.fc1(x)

        # ReLU 적용
        x = self.relu(x)

        # Class별 Raw Score인 Logits 계산
        logits = self.fc2(x)

        # 최종 Logits 반환
        return logits
```
모델은 일반적으로 다


음처럼 호출한다.
```Python
# model(x)를 호출하면 nn.Module 내부에서 forward(x)가 실행됨
logits = model(batch_x)
```
`model.forward(batch_x)`를 직접 호출하기보다는 `model(batch_x)`를 사용하는 것이 일반적이다.

## 10. MLP와 Flatten
28×28 흑백 이미지를 MLP에 넣으려면 이미지 형태를 1차원 Feature Vector로 펼쳐야 한다.
```Plain Text
(batch_size, 1, 28, 28)
↓
Flatten
↓
(batch_size, 784)
```
왜냐하면
```Plain Text
1 × 28 × 28 = 784
```
이기 때문이다.
```Python
import torch
import torch.nn as nn

class MLPClassifier(nn.Module):

    def __init__(
        self,
        input_dim=784,
        hidden_dim=128,
        num_classes=10
    ):
        super().__init__()

        # 이미지 Shape를 (Batch, Feature) 형태로 펼침
        # Batch 차원은 유지됨
        self.flatten = nn.Flatten()

        # 784개의 입력 Feature를 Hidden Feature로 변환
        self.fc1 = nn.Linear(
            input_dim,
            hidden_dim
        )

        # 비선형성을 추가
        self.relu = nn.ReLU()

        # Hidden Feature를 Class 10개의 Logits로 변환
        self.fc2 = nn.Linear(
            hidden_dim,
            num_classes
        )

    def forward(self, x):
        # (N, 1, 28, 28) → (N, 784)
        x = self.flatten(x)

        # (N, 784) → (N, hidden_dim)
        x = self.fc1(x)

        # 활성화 함수 적용
        x = self.relu(x)

        # (N, hidden_dim) → (N, num_classes)
        logits = self.fc2(x)

        # Softmax가 아닌 Raw Logits 반환
        return logits
```

## 12. Parameter 수
Hidden Size가 커지면 Parameter 수도 증가한다.
예를 들어
```Plain Text
784 → 128 → 10
```
구조에서는
```Plain Text
fc1 weight = 784 × 128
fc1 bias   = 128

fc2 bias   = 10
```
이다.
```Python
def count_parameters(model):
    # requires_grad=True인 학습 가능한 Parameter만 계산
    return sum(
        p.numel()
        for p in model.parameters()
        if p.requires_grad
    )

# 모델의 전체 학습 가능한 Parameter 수 출력
print(
    "parameters:",
    count_parameters(model)
)
```

## 15. 한 Batch 학습 Step
한 번의 학습은 다음 순서로 진행된다.
```Plain Text
zero_grad
↓
forward
↓
loss
↓
backward
↓
step
```
```Python
# 이전 Batch에서 남아 있는 Gradient 초기화
optimizer.zero_grad()

# Forward: 모델이 입력을 받아 Logits 계산
logits = model(images)

# 예측 Logits와 정답 Label을 비교해 Loss 계산
loss = criterion(
    logits,
    labels
)

# Loss를 기준으로 각 Parameter의 Gradient 계산
loss.backward()

# 계산된 Gradient를 사용해 Weight/Bias 업데이트
optimizer.step()
```

## 16. Train Loop
한 Batch 학습 Step을 DataLoader 전체에 반복하면 1 Epoch 학습이 된다.
```Python
def train_one_epoch(
    model,
    train_loader,
    criterion,
    optimizer,
    device
):

    # Dropout, BatchNorm 등을 학습 모드로 전환
    model.train()

    # Epoch 전체 Loss 누적
    total_loss = 0.0

    # Epoch 전체에서 맞힌 Sample 수
    total_correct = 0

    # Epoch 전체 Sample 수
    total_samples = 0

    # DataLoader에서 Batch를 하나씩 가져옴
    for inputs, labels in train_loader:

        # 입력 데이터를 모델과 같은 Device로 이동
        inputs = inputs.to(device)

        # Label도 같은 Device로 이동
        labels = labels.to(device)

        # 이전 Batch의 Gradient 제거
        optimizer.zero_grad()

        # Forward: 모델 예측
        outputs = model(inputs)

        # Loss 계산
        loss = criterion(
            outputs,
            labels
        )

        # Backward: Gradient 계산
        loss.backward()

        # Parameter Update
        optimizer.step()

        # 현재 Batch의 실제 Sample 수
        batch_size = inputs.size(0)

        # loss는 보통 Batch 평균이므로
        # Sample 기준 Epoch 평균을 구하기 위해 Batch Size를 곱해 누적
        total_loss += (
            loss.item()
            * batch_size
        )

        # Class 차원(dim=1)에서 가장 큰 Logit의 Index 선택
        # outputs Shape: (N, C)
        # preds Shape: (N,)
        preds = outputs.argmax(
            dim=1
        )

        # 현재 Batch에서 맞힌 개수 계산
        total_correct += (
            (preds == labels)
            .sum()
            .item()
        )

        # 전체 Sample 수 누적
        total_samples += batch_size

    # 전체 Sample 기준 평균 Loss
    avg_loss = (
        total_loss
        / total_samples
    )

    # 전체 Sample 기준 Accuracy
    avg_acc = (
        total_correct
        / total_samples
    )

    return avg_loss, avg_acc
```

## 17. Validation Loop
Validation은 Parameter를 업데이트하지 않고 현재 모델의 성능만 평가한다.
```Plain Text
Train
→ model.train()
→ backward O
→ optimizer.step O

Validation
→ model.eval()
→ torch.no_grad()
→ backward X
→ optimizer.step X
```
```Python
def validate(
    model,
    valid_loader,
    criterion,
    device
):

    # 모델을 평가 모드로 변경
    # Dropout / BatchNorm 등의 동작이 평가용으로 변경됨
    model.eval()

    # Validation 전체 Loss 누적
    total_loss = 0.0

    # 맞힌 Sample 수
    total_correct = 0

    # 전체 Sample 수
    total_samples = 0

    # Validation에서는 Gradient가 필요하지 않으므로 계산 비활성화
    # 메모리 사용량과 연산량을 줄일 수 있음
    with torch.no_grad():

        for inputs, labels in valid_loader:

            # 모델과 같은 Device로 이동
            inputs = inputs.to(device)
            labels = labels.to(device)

            # Forward만 수행
            outputs = model(inputs)

            # Validation Loss 계산
            loss = criterion(
                outputs,
                labels
            )

            # 현재 Batch Size
            batch_size = inputs.size(0)

            # Loss 누적
            total_loss += (
                loss.item()
                * batch_size
            )

            # 가장 높은 Logit을 가진 Class 선택
            preds = outputs.argmax(
                dim=1
            )

            # 맞힌 Sample 개수 누적
            total_correct += (
                (preds == labels)
                .sum()
                .item()
            )

            # 전체 Sample 수 누적
            total_samples += batch_size

    # Validation 전체 평균 Loss
    avg_loss = (
        total_loss
        / total_samples
    )

    # Validation 전체 Accuracy
    avg_acc = (
        total_correct
        / total_samples
    )

    return avg_loss, avg_acc
```

## 19. Accuracy 계산
Accuracy는 전체 Sample 중 맞힌 비율이다.
```Plain Text
Accuracy
=
맞힌 Sample 수
/
전체 Sample 수
```
```Python
def count_correct(logits, labels):

    # 각 Sample에서 가장 큰 Logit의 Class Index 선택
    # logits Shape: (batch_size, num_classes)
    preds = logits.argmax(dim=1)

    # 예측값과 정답이 같은 위치를 True로 반환
    correct_tensor = (
        preds == labels
    )

    # True의 개수를 더해 맞힌 Sample 수 계산
    correct = (
        correct_tensor
        .sum()
        .item()
    )

    # 현재 Batch 전체 Sample 수
    total = labels.size(0)

    return correct, total
```

```Plain Text

Total = 32 + 32 + 4 = 68

36 / 68
= 0.529...
```
따라서 다음과 같이 계산해야 한다.
```Plain Text
Epoch Accuracy
=
total_correct / total_samples
```

## 23. Fit 함수
Train과 Validation을 여러 Epoch 동안 반복하면 전체 학습 과정이 완성된다.
```Python
def fit(
    model,
    train_loader,
    valid_loader,
    criterion,
    optimizer,
    device,
    epochs
):

    # Epoch별 Train/Valid Metric 저장
    history = {
        "train_loss": [],
        "train_acc": [],
        "valid_loss": [],
        "valid_acc": []
    }

    # 지금까지 가장 낮은 Validation Loss
    best_valid_loss = float("inf")

    # Best Model이 나온 Epoch
    best_epoch = 0

    # Best Model의 Weight를 저장할 변수
    best_state = None

    # 지정한 Epoch 수만큼 반복
    for epoch in range(
        1,
        epochs + 1
    ):

        # 한 Epoch Train 실행
        train_loss, train_acc = train_one_epoch(
            model,
            train_loader,
            criterion,
            optimizer,
            device
        )

        # 현재 모델 Validation 평가
        valid_loss, valid_acc = validate(
            model,
            valid_loader,
            criterion,
            device
        )

        # Train Loss 저장
        history["train_loss"].append(
            train_loss
        )

        # Train Accuracy 저장
        history["train_acc"].append(
            train_acc
        )

        # Validation Loss 저장
        history["valid_loss"].append(
            valid_loss
        )

        # Validation Accuracy 저장
        history["valid_acc"].append(
            valid_acc
        )

        # 지금까지 가장 낮은 Validation Loss인지 확인
        if valid_loss < best_valid_loss:

            # Best Validation Loss 갱신
            best_valid_loss = valid_loss

            # Best Epoch 저장
            best_epoch = epoch

            # 현재 모델 Weight를 CPU에 복사해서 저장
            # 이후 모델이 계속 학습되어도 이 Weight는 유지됨
            best_state = {
                name: value
                .detach()
                .cpu()
                .clone()

                for name, value
                in model.state_dict().items()
            }

        # 현재 Epoch의 학습 결과 출력
        print(
            f"Epoch [{epoch:03d}/{epochs:03d}] "
            f"train_loss={train_loss:.4f} "
            f"train_acc={train_acc:.4f} "
            f"valid_loss={valid_loss:.4f} "
            f"valid_acc={valid_acc:.4f}"
        )

    # 전체 History와 Best Model 정보를 반환
    return (
        history,
        best_state,
        best_epoch
    )
```

# ❓ 왜 필요한가?
딥러닝 모델은 단순히 `model(x)`만 실행한다고 학습되는 것이 아니다.
데이터가 모델에 들어가기 전부터 학습이 끝날 때까지 여러 과정이 연결되어야 한다.

# 💻 직접 작성한 코드
아래 코드는 **7-3강부터 8-8강까지 배운 핵심 흐름을 하나로 연결한 종합 코드**이다.
```Python
import torch
import torch.nn as nn

from torch.utils.data import (
    TensorDataset,
    DataLoader,
    random_split
)


# ==========================================
# 1. 데이터 생성
# ==========================================

# Random 결과를 재현하기 위한 Seed 고정
torch.manual_seed(42)

# 전체 Sample 수
num_samples = 1000

# Sample 하나당 Feature 수
num_features = 4

# 분류할 Class 수
num_classes = 3

# 입력 데이터 생성
# Shape: (1000, 4)
X = torch.randn(
    num_samples,
    num_features
)

# 정답 Label을 만들기 위한 임시 Weight
# 실제 모델이 학습할 Weight가 아니라
# Synthetic Data의 정답 생성용
true_W = torch.tensor([
    [1.0, -1.0, 0.5],
    [0.5, 1.5, -1.0],
    [-1.0, 0.5, 1.0],
    [1.0, 0.2, -0.5]
])

# 각 Sample의 Class별 점수 계산
# (1000, 4) @ (4, 3)
# → (1000, 3)
label_logits = X @ true_W

# Class별 점수 중 가장 큰 Index를 정답 Label로 사용
# Shape: (1000,)
y = label_logits.argmax(
    dim=1
)


# ==========================================
# 2. Dataset 생성
# ==========================================

# X[i]와 y[i]를 하나의 Sample로 묶음
dataset = TensorDataset(
    X,
    y
)


# ==========================================
# 3. Train / Valid / Test Split
# ==========================================

# 전체의 70%를 Train으로 사용
train_size = int(
    len(dataset) * 0.70
)

# 전체의 15%를 Validation으로 사용
valid_size = int(
    len(dataset) * 0.15
)

# 남은 데이터를 Test로 사용
test_size = (
    len(dataset)
    - train_size
    - valid_size
)

# 같은 Split 결과를 재현하기 위한 Generator
generator = (
    torch.Generator()
    .manual_seed(42)
)

# Dataset 분리
train_dataset, \
valid_dataset, \
test_dataset = random_split(
    dataset,
    [
        train_size,
        valid_size,
        test_size
    ],
    generator=generator
)


# ==========================================
# 4. DataLoader 생성
# ==========================================

# Train은 Epoch마다 데이터 순서를 섞음
train_loader = DataLoader(
    train_dataset,
    batch_size=32,
    shuffle=True
)

# Validation은 순서를 섞지 않음
valid_loader = DataLoader(
    valid_dataset,
    batch_size=64,
    shuffle=False
)

# Test 역시 순서를 섞지 않음
test_loader = DataLoader(
    test_dataset,
    batch_size=64,
    shuffle=False
)


# ==========================================
# 5. 첫 Batch 확인
# ==========================================

# Train Loader에서 첫 번째 Batch 가져오기
batch_x, batch_y = next(
    iter(train_loader)
)

# Input Shape 확인
print(
    "batch_x shape:",
    batch_x.shape
)

# Label Shape 확인
print(
    "batch_y shape:",
    batch_y.shape
)

# CrossEntropyLoss를 사용할 것이므로
# Label dtype이 torch.long인지 확인
print(
    "batch_y dtype:",
    batch_y.dtype
)

# NaN / Inf 값이 없는지 검사
assert torch.isfinite(
    batch_x
).all()


# ==========================================
# 6. MLP 모델 정의
# ==========================================

class SimpleMLP(nn.Module):

    def __init__(
        self,
        input_dim=4,
        hidden_dim=32,
        num_classes=3
    ):
        # nn.Module 기본 기능 초기화
        super().__init__()

        # 입력 Feature → Hidden Feature
        self.fc1 = nn.Linear(
            input_dim,
            hidden_dim
        )

        # 비선형성 추가
        self.relu = nn.ReLU()

        # Hidden Feature → Class별 Logits
        self.fc2 = nn.Linear(
            hidden_dim,
            num_classes
        )

    def forward(self, x):

        # Shape:
        # (N, 4) → (N, 32)
        x = self.fc1(x)

        # ReLU 활성화 함수 적용
        x = self.relu(x)

        # Shape:
        # (N, 32) → (N, 3)
        logits = self.fc2(x)

        # Softmax가 아닌 Raw Logits 반환
        return logits


# ==========================================
# 7. Accuracy 계산 함수
# ==========================================

def count_correct(
    logits,
    labels
):

    # Class 차원(dim=1)에서
    # 가장 큰 Logit의 Index 선택
    # logits: (N, C)
    # preds : (N,)
    preds = logits.argmax(
        dim=1
    )

    # 예측 Class와 실제 Label 비교
    # True인 개수를 더해 맞힌 Sample 수 계산
    correct = (
        (preds == labels)
        .sum()
        .item()
    )

    # 현재 Batch 전체 Sample 수
    total = labels.size(0)

    return correct, total


# ==========================================
# 8. Train 함수
# ==========================================

def train_one_epoch(
    model,
    train_loader,
    criterion,
    optimizer,
    device
):

    # 모델을 학습 모드로 설정
    model.train()

    # Epoch 전체 Loss 누적
    total_loss = 0.0

    # 맞힌 Sample 수 누적
    total_correct = 0

    # 전체 Sample 수 누적
    total_samples = 0

    # DataLoader에서 Batch를 반복
    for inputs, labels in train_loader:

        # 입력을 모델과 같은 Device로 이동
        inputs = inputs.to(device)

        # 정답도 같은 Device로 이동
        labels = labels.to(device)

        # 이전 Batch의 Gradient 초기화
        # Gradient는 기본적으로 누적되므로 반드시 초기화
        optimizer.zero_grad()

        # Forward
        # 입력 → Model → Logits
        outputs = model(inputs)

        # Logits와 정답 Label을 비교해서 Loss 계산
        loss = criterion(
            outputs,
            labels
        )

        # Loss 기준 Gradient 계산
        loss.backward()

        # 계산된 Gradient를 이용해서
        # Weight / Bias 업데이트
        optimizer.step()

        # 현재 Batch의 실제 Sample 수
        batch_size = inputs.size(0)

        # Batch 평균 Loss에 Batch Size를 곱해
        # 전체 Sample 기준으로 누적
        total_loss += (
            loss.item()
            * batch_size
        )

        # 현재 Batch에서 맞힌 개수 계산
        correct, total = count_correct(
            outputs,
            labels
        )

        # 맞힌 개수 누적
        total_correct += correct

        # 전체 Sample 수 누적
        total_samples += total

    # Epoch 전체 평균 Loss
    avg_loss = (
        total_loss
        / total_samples
    )

    # Epoch 전체 Accuracy
    avg_acc = (
        total_correct
        / total_samples
    )

    return avg_loss, avg_acc


# ==========================================
# 9. Validation 함수
# ==========================================

def validate(
    model,
    loader,
    criterion,
    device
):

    # 모델을 평가 모드로 변경
    model.eval()

    # 전체 Loss 누적
    total_loss = 0.0

    # 전체 Correct 누적
    total_correct = 0

    # 전체 Sample 수
    total_samples = 0

    # Validation/Test에서는 Gradient가 필요 없음
    with torch.no_grad():

        for inputs, labels in loader:

            # 모델과 같은 Device로 이동
            inputs = inputs.to(device)
            labels = labels.to(device)

            # Forward만 수행
            outputs = model(inputs)

            # Loss 계산
            loss = criterion(
                outputs,
                labels
            )

            # 현재 Batch Size
            batch_size = inputs.size(0)

            # Sample 기준 Loss 누적
            total_loss += (
                loss.item()
                * batch_size
            )

            # Accuracy 계산
            correct, total = count_correct(
                outputs,
                labels
            )

            total_correct += correct
            total_samples += total

    # 전체 평균 Loss
    avg_loss = (
        total_loss
        / total_samples
    )

    # 전체 Accuracy
    avg_acc = (
        total_correct
        / total_samples
    )

    return avg_loss, avg_acc


# ==========================================
# 10. Fit 함수
# ==========================================

def fit(
    model,
    train_loader,
    valid_loader,
    criterion,
    optimizer,
    device,
    epochs
):

    # Epoch별 Metric 기록
    history = {
        "train_loss": [],
        "train_acc": [],
        "valid_loss": [],
        "valid_acc": []
    }

    # 지금까지 가장 낮은 Validation Loss
    best_valid_loss = float("inf")

    # Best Epoch
    best_epoch = 0

    # Best Weight 저장
    best_state = None

    # Epoch 반복
    for epoch in range(
        1,
        epochs + 1
    ):

        # --------------------------
        # Train
        # --------------------------

        train_loss, train_acc = (
            train_one_epoch(
                model,
                train_loader,
                criterion,
                optimizer,
                device
            )
        )

        # --------------------------
        # Validation
        # --------------------------

        valid_loss, valid_acc = (
            validate(
                model,
                valid_loader,
                criterion,
                device
            )
        )

        # --------------------------
        # History 저장
        # --------------------------

        history["train_loss"].append(
            train_loss
        )

        history["train_acc"].append(
            train_acc
        )

        history["valid_loss"].append(
            valid_loss
        )

        history["valid_acc"].append(
            valid_acc
        )

        # --------------------------
        # Best Model 선택
        # --------------------------

        # 현재 Validation Loss가
        # 지금까지 가장 낮다면 Best Model 갱신
        if valid_loss < best_valid_loss:

            best_valid_loss = valid_loss

            # 현재 Epoch 저장
            best_epoch = epoch

            # 현재 모델 Parameter 복사
            # 이후 학습으로 Weight가 바뀌어도
            # Best Weight는 그대로 유지됨
            best_state = {
                name: value
                .detach()
                .cpu()
                .clone()

                for name, value
                in model.state_dict().items()
            }

        # --------------------------
        # Epoch 로그 출력
        # --------------------------

        print(
            f"Epoch [{epoch:03d}/{epochs:03d}] "
            f"train_loss={train_loss:.4f} "
            f"train_acc={train_acc:.4f} "
            f"valid_loss={valid_loss:.4f} "
            f"valid_acc={valid_acc:.4f}"
        )

    # 전체 학습 기록과
    # Best Model 정보를 반환
    return (
        history,
        best_state,
        best_epoch
    )
```

# 🤔 내가 헷갈릴만한 부분
## 1. Dataset과 Transform은 같은가?
아니다.
```Plain Text
Dataset
→ 데이터를 어떻게 꺼낼지 정의

Transform
→ 꺼낸 데이터를 어떻게 바꿀지 정의
```
---
## 2. `batch_size=32`면 데이터가 32개뿐인가?
아니다.
```Plain Text
전체 Dataset
→ 여러 개의 Batch로 나눔

batch_size=32
→ 한 번에 최대 32개 Sample 처리
```
---
## 3. `random_split()`을 하면 Train/Valid Transform도 자동으로 나뉘는가?
아니다.
Split들은 같은 원본 Dataset을 공유하므로 서로 다른 Transform을 적용하려면 Wrapper 패턴을 사용할 수 있다.
---
## 4. `**init**()`과 `forward()`는 무엇이 다른가?
```Plain Text
__init__()
→ 모델의 부품 준비

forward()
→ 데이터가 부품을 통과하는 순서
```
---
## 5. `model(x)`와 `model.forward(x)`는 같은가?
`model(x)`를 호출하면 내부적으로 `forward(x)`가 실행된다.
일반적인 학습 코드에서는 `model(x)`를 사용한다.
---
## 6. Flatten하면 Batch 차원도 사라지는가?
사라지면 안 된다.
```Plain Text
(N, 1, 28, 28)
↓
(N, 784)
```
`N`은 그대로 유지한다.
---
## 7. `input_dim=28`이 아니라 왜 784인가?
28×28 흑백 이미지의 전체 Feature 수는
```Plain Text
1 × 28 × 28 = 784
```
이기 때문이다.
---
## 8. 마지막 Layer 뒤에 Softmax를 넣어야 하는가?
`CrossEntropyLoss`를 사용할 때는 일반적으로 넣지 않는다.
```Plain Text
Linear
↓
Raw Logits
↓
CrossEntropyLoss
```
---
## 9. `optimizer.zero_grad()`는 왜 필요한가?
Gradient가 기본적으로 누적되기 때문이다.
```Plain Text
Batch 1 Gradient
+
Batch 2 Gradient
```
가 의도치 않게 합쳐지는 것을 방지하기 위해 매 Batch마다 초기화한다.
---
## 10. `loss.item()`은 왜 쓰는가?
Tensor 형태의 Loss를 출력하거나 기록하기 좋은 Python 숫자로 바꾸기 위해 사용한다.
하지만 계산 그래프가 사라지므로 `backward()`에는 사용할 수 없다.
```Python
# 기록용
value = loss.item()

# Gradient 계산용
loss.backward()
```
---
## 11. `model.eval()`과 `torch.no_grad()`는 같은가?
아니다.
```Plain Text
model.eval()
→ 모델의 동작 모드 변경

torch.no_grad()
→ Gradient 계산 중지
```
Validation에서는 보통 둘 다 사용한다.
---
## 12. Accuracy에서 왜 `argmax(dim=1)`인가?
Logits Shape가
```Plain Text
(batch_size, num_classes)
```
이기 때문이다.
`dim=1`이 Class 방향이다.
---
## 13. Batch Accuracy를 평균 내면 안 되는 이유는?
마지막 Batch 크기가 다를 수 있기 때문이다.
따라서
```Plain Text
total_correct / total_samples
```
를 사용한다.
---
## 14. Train과 Validation의 가장 큰 차이는?
```Plain Text
Train
→ Parameter 업데이트

Validation
→ Parameter 업데이트 X
```
Train에는
```Plain Text
backward()
optimizer.step()
```
이 있지만 Validation에는 없다.
---
## 15. 마지막 Epoch 모델이 가장 좋은 모델인가?
항상 그렇지는 않다.
Validation Loss가 가장 낮았던 Epoch를 Best Model로 선택할 수 있다.
---
## 16. Test 결과를 보고 다시 모델을 수정해도 되는가?
가능하면 하지 않는다.
```Plain Text
Validation
→ 모델 선택

Test
→ 최종 평가
```
역할을 분리해야 한다.
