## 1. 핵심 개념
- 하이퍼파라미터 → 학습 전에 사람이 정하는 모델의 설정값
- CV → 여러 fold로 나누어 후보를 반복 평가하는 방법
- Grid Search → 정해진 하이퍼파라미터 조합을 빠짐없이 탐색
- Random Seach → 넓은 후보 공간에서 정해진 개수만큼 무작위 탐색
- AP →  불균형 데이터에서 양성의 순위 성능을 평가하는 지표
- CV 평균 AP → 후보의 평균적인 성능
- Fold 표준편차 → fold마다 성능이 얼마나 흔들리는지 나타냄
- 공정한 후보 선정 → 모든 후보에게 같은 데이터 · fold · 평가지표 · 평가 횟수를 적용
- Sealed Test → 모든 후보 선택이 끝난 후 최종 성능을 확인하는 데이터
- Pipeline → 전처리 · 불균형 처리 · 모델을 하나의 흐름으로 묶는 방법
- ColumnTransformer → 수치형 · 범주형 데이터에 서로 다른 전처리 적용
- RandomOverSampler →  소수 클래스 데이터를 복제하여 불균형 완화
- Refit → 선택된 설정으로 Dev 전체 데이터를 다시 학습
- Sealed Test → 최종후보를 정하기 전에는 사용하지 않는 Test
- Inference → 학습된 모델로 새로운 데이터를 예측
- Joblib → 학습된 Pipeline을 저장하고 다시 불러오는 방법

## 2. ❓ 왜 필요한가?
- **1️⃣ 왜 CV 기반으로 하이퍼파라미터를 탐색하는가?**
- 한 번의 Validation 분할에 우연히 잘 맞는 후보를 선택할 수 있기 때문에
- 여러 fold에서 반복 평가하여 평균 성능과 변동을 확인하기 위해
- **2️⃣ 왜 후보를 공정하게 비교해야 하는가?**
- 같은 데이터, 같은 4-fold, 같은 AP 평가 횟수, 같은 평가 지표를 사용해야 함
→ 그래야 탐색 방법이나 후보 자체의 차이를 공정하게 비교할 수 있음.
- **3️⃣ 왜 Pipeline을 사용하는가?**
- 전처리와 모델을 따로 관리하면 CV과정에서 전처리 기준이 Validation 데이터에 영향을 받을 수 있음
- Pipeline으로 묶으면:
전처리 → 불균형 처리 → 모델의 순서를 하나로 관리할 수 있음.
특히 CV에서는 각 fold의 Train 데이터에서 전처리와 sampler가 학습되도록 할 수 있음
- **4️⃣ 왜 Test를 마지막에 한 번만 사용하는가?**
- Test결과를 보고 하이퍼파라미터나 모델을 다시 수정하면 Test가 최종 평가 데이터가 아니라 선택 데이터가 되기 때문
- → 후보선택은 Dev + CV에서 
- → Test는 최종 모델 확정 후 한번만

# ❓ 헷갈렸던 부분
### CV와 Test의 차이
> **CV → 좋은 후보를 고르기 위해 사용**
### Pipeline의 fit과 predict
> **fit → 전처리 기준과 모델을 학습**
### Sampler의 역할
> **학습할 때만 불균형을 처리하고, 예측할 때는 실행하지 않는다.**
## 🧠 내가 이해한 내용
- 하이퍼파라미터는 여러 후보를 만들어 동일한 CV 환경에서 비교해야 함
- 후보를 비교하기 전에 평가 지표, CV 방식, 후보 수, 동률 기준 등을 미리 정해야 함
- CV 결과를 이용해 최종 후보를 선택한 후 Dev 전체 데이터로 다시 학습함
- Test는 후보 선택에 사용하지 않고 마지막에 한번만 평가함
- 전처리, 불균형 처리, 모델을 Pipeline으로 묶으면 학습과 예측의 처리 순서를 일관되게 유지 할 수있음
- 최종 Pipeline을 저장하고 reload하면 같은 새 데이터에 대해 같은 결과를 재현할 수 있는지 확인할 수있다.

## 오늘 배운 것 중 중요한 것
1. 하이퍼파라미터는 CV로 비교
> 여러 fold에서 평가하여 평균 성능과 변동을 확인
1. 후보는 공정하게 비교
> 같은 데이터 + 같은 fold + 같은 평가 지표 + 같은 평가 횟수
1. Test는 절대 후보 선정에 사용 X 
> Test를 보고 모델을 수정하면 Test가 선택 데이터가 됨
1. Pipeline으로 전체 과정을 묶기
> 전처리 → 불균형 처리 → 모델을 하나의 흐름으로 관리
1. 최종 Pipeline은 저장해서 재사용
> 저장 → reload → 같은 입력으로 예측 → 결과가 같은지 확

## 한 줄 정리
> 하이퍼파라미터는 같은 CV 조건에서 공정하게 비교하고, 선택한 전처리·불균형 처리·모델을 하나의 Pipeline으로 묶은 뒤, 최종 후보를 Dev 전체로 재학습하고 Test는 마지막에 한 번만 평가한다.
