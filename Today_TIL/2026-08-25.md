# ❓ 왜 필요한가?
딥러닝 모델은 단순히 데이터를 넣고 결과를 출력하는 것으로 끝나지 않는다.
모델이 예측한 값과 실제 정답의 차이를 계산하고, 그 차이를 줄이는 방향으로 모델의 파라미터를 수정해야 한다.
전체 흐름은 다음과 같다.
```Plain Text
입력 데이터
    ↓
Forward
    ↓
예측값
    ↓
Loss 계산
    ↓
Backward
    ↓
Gradient 계산
    ↓
Optimizer
    ↓
Parameter Update
```
이 과정을 반복하면서 모델의 Weight와 Bias를 수정해야 한다.
또한 실제 데이터는 수천 개에서 수백만 개까지 존재할 수 있기 때문에 모든 데이터를 한 번에 모델에 넣기 어렵다.
그래서 데이터를 관리하는 `Dataset`과 데이터를 Batch 단위로 제공하는 `DataLoader`가 필요하다.

# 🧠 핵심 개념
## 1. requires_grad
`requires_grad=True`는 해당 Tensor에 대해 gradient를 계산하도록 설정하는 것이다.
```Plain Text
import torch
x=torch.tensor(2.0,requires_grad=True)
y = x ** 2
print(x.requires_grad)
```
`x`는 gradient 계산 대상이다.
즉,
```Plain Text
x
↓
연산
↓
y
↓
gradient 계산
```
PyTorch는 연산 과정을 계산 그래프로 기록한다.
---
## 2. Leaf Tensor
Leaf Tensor는 사용자가 직접 만든 Tensor 중 계산 그래프의 시작점에 있는 Tensor이다.
```Plain Text
x=torch.tensor(2.0,requires_grad=True)
print(x.is_leaf)
```
결과:
```Plain Text
True
```
Leaf Tensor는 보통 `.grad`에 gradient가 저장된다.
```Plain Text
x = torch.tensor(2.0,requires_grad=True)
y = x ** 2
y.backward()
print(x.grad)
```
결과:
```Plain Text
tensor(4.)
```
---
## 3. Non-leaf Tensor
연산 결과로 만들어진 Tensor는 보통 Non-leaf Tensor이다.
```Plain Text
x = torch.tensor(2.0,requires_grad=True)

y=x * 3

print(x.is_leaf)
print(y.is_leaf)
```
결과:
```Plain Text
True
False
```
구조는 다음과 같다.
```Plain Text
Leaf Tensor
x
↓
연산
↓
Non-leaf Tensor
y
```
기본적으로 gradient는 Leaf Tensor의 `.grad`에 저장된다.
---
## 4. .grad
`.grad`에는 해당 Tensor의 gradient가 저장된다.
```Plain Text
x = torch.tensor(3.0,requires_grad=True)

y= x ** 2

y.backward()

print(x.grad)
```
수식으로 보면,
```Plain Text
y = x²

dy/dx = 2x
```
x가 3이면,
```Plain Text
2 × 3 = 6
```
따라서,
```Plain Text
x.grad = 6
```
---
## 5. loss.backward()
`loss.backward()`는 Loss를 기준으로 역전파를 수행한다.
```Plain Text
pred=model(x)

loss=criterion(pred,y)
0
loss.backward()
```
흐름은 다음과 같다.
```Plain Text
Forward
입력 → 모델 → 예측값

↓

Loss
예측값과 정답 비교

↓

Backward
Loss를 기준으로 역방향 미분

↓

.grad
각 Parameter의 Gradient 저장
```
중요한 점은,
```Plain Text
loss.backward()
```
는 Parameter를 직접 변경하지 않는다는 것이다.
Gradient만 계산해서 `.grad`에 저장한다.
---
## 6. backward 전과 후
Backward 전에는 gradient가 없다.
```Plain Text
model=nn.Linear(2,1)
print(model.weight.grad)
print(model.bias.grad)
```
결과:
```Plain Text
None
None
```
Backward를 실행하면,
```Plain Text
loss.backward()
print(model.weight.grad)
print(model.bias.grad)
```
`.grad`에 값이 저장된다.
---
## 7. Gradient Shape
Gradient의 Shape는 Parameter의 Shape와 같다.
예를 들어,
```Plain Text
model=nn.Linear(2,1)
```
Weight Shape:
```Plain Text
(1, 2)
```
Gradient Shape:
```Plain Text
(1, 2)
```
확인 코드:
```Plain Text
print(model.weight.shape)
print(model.weight.grad.shape)
```
즉,
```Plain Text
Parameter Shape
=
Gradient Shape
```
---
## 8. Loss는 Scalar
일반적인 학습에서는 Loss가 Scalar인 것이 기본이다.
```Plain Text
print(loss.ndim)
print(loss.shape)
```
Scalar Tensor라면,
```Plain Text
loss.ndim = 0
loss.shape = torch.Size([])
```
여러 개의 Loss가 있다면 평균 등을 사용해 하나의 Scalar Loss로 만들 수 있다.
```Plain Text
loss_each=criterion(pred,y)
loss=loss_each.mean()
```
---
## 9. Gradient는 누적된다
PyTorch는 기본적으로 Gradient를 자동으로 초기화하지 않는다.
```Plain Text
w=torch.tensor(2.0,requires_grad=True)

loss1= w ** 2

loss1.backward()

print(w.grad)
```
결과:
```Plain Text
tensor(4.)
```
다시 backward를 하면,
```Plain Text
loss2=w**2

loss2.backward()

print(w.grad)
```
결과:
```Plain Text
tensor(8.)
```
기존 Gradient에 새로운 Gradient가 더해진다.
```Plain Text
기존 Gradient
+
새로운 Gradient
=
누적된 Gradient
```
---
## 10. optimizer.zero_grad()
Gradient가 누적되지 않도록 초기화한다.
```Plain Text
optimizer.zero_grad()
```
일반적인 학습에서는 매 Step마다 실행한다.
---
## 11. optimizer.step()
`optimizer.step()`은 `.grad`에 저장된 Gradient를 사용해서 실제 Parameter를 업데이트한다.
```Plain Text
optimizer.step()
```
흐름:
```Plain Text
loss.backward()
        ↓
Gradient 계산
        ↓
Parameter.grad 저장
        ↓
optimizer.step()
        ↓
Weight / Bias 업데이트
```
Gradient Descent의 기본 개념은,
```Plain Text
새로운 Parameter
=
기존 Parameter
-
Learning Rate × Gradient
```
즉,
```Plain Text
w = w - learning_rate × gradient
```
---
## 12. 올바른 Training Step 순서
가장 중요한 학습 순서는 다음과 같다.
```Plain Text
optimizer.zero_grad()

pred=model(x)

loss=criterion(pred,y)

loss.backward()

optimizer.step()
```
순서로 보면,
```Plain Text
1. zero_grad
   ↓
이전 Gradient 초기화

2. forward
   ↓
예측값 계산

3. loss
   ↓
예측값과 정답 비교

4. backward
   ↓
Gradient 계산

5. step
   ↓
Parameter 업데이트
```
---
## 13. model.train()
```Plain Text
model.train()
```
모델을 학습 모드로 변경한다.
Dropout, BatchNorm 같은 Layer가 학습 방식으로 동작한다.
학습 함수에서는 보통 가장 먼저 사용한다.
```Plain Text
model.train()
```
---
## 14. model.eval()
```Plain Text
model.eval()
```
모델을 평가 모드로 변경한다.
Dropout과 BatchNorm 등의 동작 방식이 평가 모드로 변경된다.
하지만 중요한 점은,
```Plain Text
model.eval()
≠
Gradient 계산 중지
```
`model.eval()`만으로 Gradient 추적이 꺼지는 것은 아니다.
---
## 15. torch.no_grad()
평가나 추론에서는 Gradient가 필요하지 않다.
```Plain Text
model.eval()

with torch.no_grad():


pred=model(x)
```
이렇게 하면 계산 그래프를 만들지 않는다.
따라서,
```Plain Text
메모리 사용 감소
+
불필요한 Gradient 계산 방지
```
평가에서는 보통,
```Plain Text
model.eval()

withtorch.no_grad():

pred=model(x)

loss=criterion(pred,y)
```
형태를 사용한다.
---
## 16. detach()
`detach()`는 Tensor를 계산 그래프에서 분리한다.
```Plain Text
pred=model(x)

pred_detached = pred.detach()
```
`pred_detached`는 이전 계산 그래프와 연결되지 않는다.
주로 결과를 저장하거나 NumPy로 변환할 때 사용한다.
```Plain Text
pred_np=pred.detach().cpu().numpy()
```
하지만 학습 중간에 너무 일찍 `detach()`를 사용하면 Gradient가 끊길 수 있다.
```Plain Text
# 잘못된 예시
pred=model(x).detach()
loss=criterion(pred,y)
loss.backward()
```
이 경우 모델 Parameter까지 Gradient가 전달되지 않을 수 있다.

## 17. Dataset
Dataset은 데이터를 하나씩 어떻게 꺼낼지를 정의한다.
Dataset은 주로 두 가지를 구현한다.
```Plain Text
__len__()
```
전체 데이터 개수를 반환한다.
```Plain Text
__getitem__(idx)
```
특정 Index의 데이터를 반환한다.
구조:
```Plain Text
Dataset
│
├── __len__()
│   └── 전체 데이터 개수
│
└── __getitem__(idx)
    └── idx번째 데이터
```
---
## 18. TensorDataset
이미 Tensor로 준비된 데이터를 쉽게 묶을 수 있다.
```Plain Text
from torch.utils.data import TensorDataset

dataset = TensorDataset(X,y)
```
예를 들어,
```Plain Text
X= torch.randn(20,4)

y=torch.tensor(
    [0,1]*10,
    dtype=torch.long
)

dataset=TensorDataset(X,y)
```
`dataset[0]`을 실행하면,
```Plain Text
X[0]
y[0]
```
이 하나의 Sample로 반환된다.

## 19. Custom Dataset
실제 프로젝트에서는 이미지, CSV, JSON, 텍스트 등 다양한 형태의 데이터를 사용한다.
이 경우 직접 Dataset을 만든다.
```Plain Text
from torch.utils.data importDataset

class MyDataset(Dataset):

    def__init__(self,features,labels):
		# 데이터 저장
    self.features=features
    self.labels=labels
    
    def__len__(self):
       # 전체 샘플 수 반환
       returnlen(self.features)

def__getitem__(self,idx):
	 # idx번째 데이터 반환
   return self.features[idx],self.labels[idx]
```

## 21. Batch
전체 데이터를 한 번에 학습시키지 않고 여러 개로 나누어 학습한다.
예를 들어,
```Plain Text
전체 데이터: 100개

batch_size = 20
```
그러면,
```Plain Text
Batch 1 → 20개
Batch 2 → 20개
Batch 3 → 20개
Batch 4 → 20개
Batch 5 → 20개
```
이렇게 데이터를 나누어 모델에 전달한다.

import torch 
from torch.utils.dataimportDataset

class MyDataset(Dataset):
		
		def__init__(self,features,labels):
		   
		   # Feature 저장
		   self.features=features
		   
		   # Label 저장

		model.parameters(),
		lr=0.001

		logits,
		batch_y

# Parameter 업데이트

print("loss:", loss.item())

# 🤔 내가 헷갈릴만한 부분
## 1. backward()와 step()의 차이
```Plain Text
loss.backward()
```
는 Gradient를 계산한다.
```Plain Text
Parameter 값 변경 ❌
Gradient 계산 ⭕
```
반면,
```Plain Text
optimizer.step()
```
는 실제 Parameter를 변경한다.
```Plain Text
Gradient 계산 ❌
Parameter 업데이트 ⭕
```
---
## 2. zero_grad()는 왜 필요한가?
PyTorch의 Gradient는 기본적으로 누적된다.
```Plain Text
첫 번째 backward

grad = 4

↓

두 번째 backward

grad = 기존 grad + 새로운 grad

↓

grad = 8
```
그래서 일반적인 학습에서는 매 Step마다,
```Plain Text
optimizer.zero_grad()
```
를 사용한다.

## 3. model.eval()과 no_grad()의 차이
```Plain Text
model.eval()
```
은 모델의 동작 모드를 평가 모드로 변경한다.
```Plain Text
torch.no_grad()
```
는 Gradient 추적을 중지한다.
따라서 평가할 때는 보통 둘 다 사용한다.
```Plain Text
model.eval()

withtorch.no_grad():

pred=model(x)
```

## 4. detach()와 no_grad()의 차이
`detach()`는 특정 Tensor를 계산 그래프에서 분리한다.
```Plain Text
pred=model(x)

pred=pred.detach()
```
`torch.no_grad()`는 해당 코드 블록 전체에서 Gradient 추적을 끈다.
```Plain Text
with torch.no_grad():

pred = model(x)
```

# 💡 복습용 핵심 공식
## Gradient
```Plain Text
Gradient
=
Loss가 Parameter에 따라 얼마나 변하는지
```
---
## Gradient Descent
```Plain Text
새 Parameter
=
기존 Parameter
-
Learning Rate × Gradient
```
코드에서는,
```Plain Text
loss.backward()
        ↓
Gradient 계산

optimizer.step()
        ↓
Parameter 업데이트
```
---
## Training Step
```Plain Text
optimizer.zero_grad()

↓

Forward

↓

Loss

↓

loss.backward()

↓

optimizer.step()
```
코드:
```Plain Text
optimizer.zero_grad()

pred=model(x)

loss=criterion(pred,y)

loss.backward()

optimizer.step()
```
---

```Plain Text
model.eval()

↓

torch.no_grad()

↓

Forward

↓

Loss / Metric 확인
```

```Plain Text
model.eval()

with torch.no_grad():

pred=model(x)

loss=criterion(pred,y)
```
