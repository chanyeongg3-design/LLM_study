# ❓ 왜 필요한가?
1. Linera Layer만으로는 한계가 있다.
- 신경망에서 Linear Layer는 입력 데이터를 새로운 feature로 변환한다.
하지만 Linear Layer만 여러 개 쌓는다고 해서 복잡한 비선형 패턴을 학습할 수 있는 것은 아니다
그래서 중간에 활성화 함수를 넣어 비선형성을 추가한다.
그리고 모델이 출력한 logits를 문제에 맞게 해석하기 위해 sigmoid 또는 softmax를 사용한다.
- 이진 분류
logits → sigmoid → 확률 → 0 또는 1
- 다중 분류
logits → softmax → class별 확률 → 가장 큰 값 선택 
# 🧠 핵심 개념
1. ReLU: 가장 기본적이고 자주 사용하는 활성화 함수이다.
- ReLU(x) = max(0, x)
- x < 0 → 0,  x > 0 → 그대로 통과
1. ReLU의 특징
- 계산이 단순함
→ max(0, x)
- 양수 영역
→ gradient가 1
- 음수 영역
→ 출력이 0
→ gradient가 0이 될 수 있음
- Shape
→ 변경하지 않음
→ 값만 변경
1. ReLU는 Shape를 바꾸지 않는다
- ReLU는 feature 개수나 Tensor의 차원을 변경하는 Layer가 아니다
- 즉, Linear는 feature 개수를 변경할 수 있다
ReLU는 feature 개수는 변경 X, 값만 변경 O
1. MLP에서 ReLU 위치: 일반적인 MPL에서는 은닉층의 Linear 뒤에 ReLU를 사용한다. 
- Input → Linear → ReLU → Linear → ReLU → Linear → logits
- Linear가 feature를 변환하고, ReLU가 그 결과에 비선형성을 추가한다.
- ⚠️ 마지막 출력층 뒤에 ReLU를 무조건 붙이지는 않는다.
출력층은 문제에 따라 다르게 설계해야 한다. 
1. Dead ReLU
- ReLU는 음수 입력을 모두 0으로 만든다.
뉴런 출력이 계속 음수 → ReLU 적용 → 계속 0 출력 → gradient가 0이 될 수 있음 → 학습이 잘 안 될 수 있음
이러한 상황을 Dead ReLU 라고 한다.
> ReLU는 음수 영역에서 gradient가 0이 될 수 있다. 
1. Sigmoid: 주로 이진 분류에서 사용한다.
- 모델이 출력한 logit을 0 ~ 1 사이의 값으로 변환한다.
- logit → sigmoid → 0 ~ 1 → 확률처럼 해석
logit이 큰 음수 → 0에 가까움   |    logit = 0 → 0.5   |    logit이 큰 양수 → 1에 가까움
이진 분류의 전체 흐름
- 모델 → logit 1개 → Sigmoid → 확률 → Threshold → 0 또는 1
보통 0.5를 기준으로 예측한다. 
확률 ≥ 0.5 → class 1   |   확률 < 0.5 → class 0
1. BCEWithLogitsLoss와 Sigmoid
- 이진 분류에서 BCEWithLogitsLoss를 사용할 경우 모델 마지막에 직접 sigmoid를 넣지 않는다.
학습: 모델 → logit → BCEWithLogitsLoss 
- 예측할 때만 Sigmoid를 적용해 확률을 확인한다
예측: logit → Sigmoid → 확률 → Treshold → 예측값
즉, 학습 → logits 그대로 사용  |   예측 → Sigmoid 적용
일반적인 shape:
logits → (batch_size, 1)  |  target → (batcj_size, 1)
Target은 보통 float 타입을 사용한다. 
1. Softmax: 주로 다중 분류에서 사용한다. 
- 모델이 class 수만큼 출력한 logits를 각 class의 확률처럼 변환한다.
```Plain Text
logits
[2.0, 1.0, 0.1]
   
   ↓ Softmax
   
   class별 확률
[0.66, 0.24, 0.10]
```
Softmax의 중요한 특징:
```Plain Text
각 class 값은 확률처럼 해석 가능

모든 class 확률의 합 = 1
```
Softmax 전체 흐름:
```Plain Text
logits
↓
Softmax
↓
class별 확률
↓
가장 큰 확률 선택
↓
예측 class
```
1. CrossEnytropyLoss와 Softmax
- 다중 분류에서 CrossEntropyLoss를 사용할 때도 모델 마지막에 Softmax를 직접 넣지 않는다. 
```Plain Text
학습

모델
↓
raw logits
↓
CrossEntropyLoss
즉,
model = nn.Sequential(
    nn.Linear(10, 32),
    nn.ReLU(),
    nn.Linear(32, 5)
)

마지막 출력은 class 5새에 대한 raw logits이다.

예측할 때는 필요에 따라 Softmax를 적용할 수 있다.
logits -> Softmax -> class별 확률 
하지만 예측 class 번호만 필요하다면 Softmax 없이 바로 argmax를 사용할 수 있다. 
```
1. argmax: 가장 큰 값을 가진 위치를 반환한다.
- `preds = torch.argmax(logits, dim=1)`

```Plain Text
    logits

[[1.2, 3.5, 0.4],
[4.1, 1.2, 2.0]]
    
    ↓ argmax
    
    [1, 0]

첫 번째 샘플은 index 1이 가장 크고,
두 번째 샘플은 index 0이 가장 크다는 의미

다중 분류에서는 보통:
logits shape
(batch_size, num_class)

target shape
(batch_size, )    

Target의 dtype은 보통:: torch.long 이다 
```

import torch
import torch.nn as nn
# 음수, 0, 양수가 섞인 Tensor 생성

ReLU를 사용한 MLP
```Plain Text
import torch
import torch.nn as nn

# 여러 Layer를 순서대로 연결
model = nn.Sequential(
		nn.Linear(4, 16), # 입력 feature 4개 → 16개
	  nn.ReLU(),        # 음수 값을 0으로 변경
	            
		nn.Linear(16, 8), # feature 16개 → 8개
		nn.ReLU(), # 다시 relu 적용
		
		nn.Linear(8, 3)   # 최종 class 3개에 대한 logits 출력 
)
# 샘플 5개, feature 4개인 입력 생성
x = torch.randn(5, 4)

# x를 모델에 입력
logits = model(x)

# 입력과 출력 shape 확인
print("x shape:", x.shape)
print("logits shape:", logits.shape)
```
nn.Module 방식
```Plain Text
import torch
import torch.nn as nn

class ReLUClassifier(nn.Module):

		def __init__(self):
				super().__init__()
				
				# 입력 4개 → 은닉 feature 16개  
				self.fc1 = nn.Linear(4, 16)
				
				# 활성화 함수 ReLU
				self.relu = nn.ReLU()
				
				# 은닉 feature 16개 → class 3개 
				self.fc2 = nn.Linear(16, 3)
				
		def forward(self, x):
				# 첫번째 Linear Layer
				x = self.fc1(x)
				
				# x에 ReLU 적용
				x= self.relu(x)
				
				# 최종 logits 출력 
				logits = self.fc2(x)
				
				return logits

# 모델 생성				
model = ReLUClassifier()

# 샘플 5개, feature 4개 입력
x = torch.randn(5, 4)

# 모델 실행
logits = model(x)

# 출력 shape 확인
print("logits shape:", logits.shape)
```
ReLU의 Gradient 확인
```Plain Text
import torch
import torch.nn as nn

# gradient를 계산할 수 있는 Tensor 생성
x = torch.tensor(
		[-2.0, 3.0],
		requires_grad=True
)

# ReLU 생성
relu = nn.ReLU()

# ReLU 적용
y = relu(x)

# 여러 값을 하나의 loss의 값으로 합침
loss = y.sum()

# gradient 계산
loss.backward()

# 입력, ReLU 결과 , gradient 확인 
print("x:", x) # 입력값
print("relu(x):", y) ReLU 결과
print("x.grad:", x.grad) gradient 확인 
```
Sigmoid를 이용한 이진 분류 예측
```Plain Text
import torch

# 모델이 출력했다고 가정한 logits
logits = torch.tensor([
		[-2.0],
		[1.0],
		[3.0]
])

# sigmoid를 적용해 0 ~ 1 사이의 확률로 변환
probs = torch.sigmoid(logits)

# 확률이 0.5 이상이면 1, 아니면 0
preds = (probs >= 0.5).float()

# 확률과 최종 예측값 출력 
print("probs:", probs)
print("preds:", preds)
```
Softmax와 argmax를 이용한 다중 분류 예측
```Plain Text
import torch

# 샘플이 2개에 대한 class별 logits
logits = torch.tensor([
		[1.0, 3.0, 0.5],
		[2.0, 0.3, 1.0]
])

# Softmax를 class별 확률 계산
probs = torch.softmax(logits, dim=1) # dim =1, class 방향을 기준으로 계산

preds = torch.argmax(logits, dim=1) # 가장 큰 logit의 위츠를 예측 class로 선택

# class별 확률과 최종 예측값 출력 
print("probs:", probs)
print("preds:", preds)
```

# 🤔 내가 헷갈렸던 부분
1. ReLU는 만들기만 하면 적용되는 것이 아니다
relu = nn.ReLU()

직접 적용해야 한다. 
1. Sigmoid와 Softmax의 차이 
```Plain Text
Sigmoid
→ 주로 이진 분류
→ 각각의 값을 0 ~ 1 범위로 변환

Softmax
→ 주로 다중 분류
→ 여러 class 값을 비교
→ 전체 합이 1이 되는 확률 분포 생성
```

# 📝 오늘의 한 줄 정리
> ReLU은 은닉층에서 비선형성을 추가하는 활성화 함수이고, 이진 분류에서는 sigmoid로 logit을 확률처럼 해석하며, 다중 분류에서는 Softmax로 class별 확률을 확인한다.
> 학습할 때는 BCEWithLogitsLoss와 CrossEntropyLoss에 raw logits를 전달하고, 
> 최종 예측할 때 Sigmoid/Softmax/argmax를 목적에 맞게 사용한다.
