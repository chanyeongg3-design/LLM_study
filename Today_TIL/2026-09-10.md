# 2026-09-10(Loss Function과 Optimizer)

## 📚 오늘 배운 것:
### 1-1강 — Logits / softmax / Log-softmax와 수치 안정성
- Logits은 분류 모델이 출력하는 클래스별 원시 점수(raw score)이다.
- Logits은 음수가 될 수 도 있고 합이 1일 필요도 없으므로 확률이 아니다.
- Softmax는 logits를 모든 값이 0 이상이고 합이 1인 확률 분포로 변환한다.
- 큰 logtis에 바로 `exp( )` 를 적용하면 inf, nan이 발생할 수 있다.
- 이를 막기 위해 각 샘플의 가장 큰 logits을 빼는 max trick을 사용한다.
- Log-Softmax는 확률의 로그값이며 이후 Cross Entropy 계산과 연결된다.
- 배치 분류에서는 보통 클래스 축인 마지막 축 `axis=-1` 을 기준으로 Softmax를 계산한다.
> **Logits → Max Trick → Softmax → Probability**
### 1-2강 — MSE / BCE / Cross Entropy 구현과 검증
손실 함수는 예측과 정답의 차이를 하나의 숫자로 표현한다.
문제 유형과 모델 출력, 정답 형태를 보고 Loss를 선택해야 한다. 

MSE
- 예측과 정답의 차이를 제곱한 뒤 평균을 낸다.
- 양수와 음수 오차가 서로 상쇄되는 것을 막는다.
- 큰 오차가 더 강하게 반영된다. 
```Plain Text
MSE
→ Error
→ Error²
→ 평균
→ MSE
```
BCE
- 정답이 0 또는 1인 이진 분류에서 사용한다.
- 정답이 1이면 p가 높을수록 Loss가 작아지고, 정답이 0이면 1-p가 높을수록 Loss가 작아진다.
- log(0)을 피하기 위해 확률 기반 구현에서는 `np.clip()` 을 사용할 수 있다.
- 실제 프레임워크에서는 logits를 직접 받는 BCEWithLogitsLoss를 사용할 수 있다.
Cross Entropy
- 다중 분류에서 클래스별 logits와 정답 클래스 인덱스를 사용한다.
- 정답 클래스의 negative log-probability를 Loss로 사용한다.
- 정답 클래스 확률이 높아질수록 Loss는 작아진다. 
```Plain Text
Logits
→ Log-Softmax
→ 정답 클래스 선택
→ -log(p)
→ 평균
→ Cross Entropy
```
### 2-1강 — Cradient Descent와 파라미터 갱신
- 학습은 현재 파라미터로 예측하고, Loss를 계산하고, Gradient을 구한 뒤 파라미터를 수정하는 과정을 반복한다.
- Gradient는 Loss가 증가하는 방향을 나타낸다.
- 따라서 Loss를 최소화하려면 Gradient의 반대 방향으로 이동해야 한다.
- Learning Rate는 한 번의 업데이트에서 얼마나 이동할지를 결정한다.
```Python
parameter = parameter - learning_rate * gradient
```
```Python
예측 → Loss → Gradient → parameter Updeate → 다시 예측 
```
> Learning Rate가 너무 작으면 수렴이 느리고, 너무 크면 최소점을 지나쳐 진동하거나 발산할 수 있다.  
### 2-2강 — SGD / Momentum / Adam 직관 비교
Optimizer는 **계산된 Gradient를 이용해 모델 파라미터를 갱신하는 규칙**이다.
세 Optimizer의 핵심 차이는 **Gradient 정보를 어떻게 기억하고 사용하는가** 이다.

```Plain Text
SGD

현재 Gradient → Parameter Update
→ 가장 단순하며 추가 상태가 거의 필요하지 않는다.

Momentum

Velocity = beta * velocity + gradient
parameter -= learning_rate * velocity
→ 이전 이동 방향을 velocity에 누적하여 같은 방향의 Gradient가 반복될 때 이동을 부드럽게 이어간다. 

Adam

Gradient 1. 방향 정보 → m
				 2. 크기 정보 → v 
				               ↓
				         parameter Update
- m : Gradient의 이동 평균
- v : Gradient 제곱의 이동 평균
- 초기 이동 평균이 0쪽으로 치우치는 현상을 줄이기 위해 bias correction을 사용한다.  
```

### 2. Logits와 Probability 구분
- Logits : 모델의 원시 점수(raw score)
- Softmax(logits) : 합이 1인 Probability
Ex) 
logits = [2.0, 1.0, -0.5] 에서는 첫 번째 클래스가 가장 높은 점수를 받았지만 아직 확률은 아니다.
### 3.  Loss Function 선택
무조건 Loss 이름을 외우기보다 **모델 출력과 정답 형태**를 먼저 봐야 한다. 
**회귀**
- 실수 예측
- MSE
이진 분류
- 0 / 1
- BCE
다진 분류
- 여러 클래스 중 하나
- Cross Entropy
### 4. Gradient Descent 핵심 공식 
`parameter -= learning_rate * gradient` 
- `Gradient` = Loss가 증가하는 방향
- `Learning Rate` = 한 번에 얼마나 움직일지
- `-` = Loss가 감소하는 반대 방향으로 이동 
### 5. Optimizer 차이
- SGD → 현재 Gradient 사용
- Momentum →  현재 Gradient + 과거 방향
- Adam → Gradient 방향 + Gradient 크기 
> Optimizer가 완전히 다른 목표를 가지는 것이 아니라 모두 Gradient를 이용해 Loss를 줄이는 것이 목표이고, Gradient 정보를 처리하는 방법이 다르다. 

## 왜❓:
### Q1. 왜 Logits를 Softmax로 바꾸는가?
Logits은 음수가 가능하고 합이 1이 아니기 떄문에 확률로 해석하기 어렵다. 
```Plain Text
Softmax를 적용하면

모든 값 ≥ 0
+
전체 합 = 1
이 되어 클래스별 확률 분포로 해석할 수 있다. 
```
### Q2. 왜 Softmax 전에 최댓값을 빼는가? 
큰 logits에 `exp()` 를 적용하면 Overflow가 발생할 수 있기 때문이다. 
```Python
[1000, 1001, 1002]
       ↓
     exp()
       ↓
[inf, inf, inf]
       ↓
inf / inf
       ↓
nan

그래서 
shifted = logits - np.max(logits)를 사용한다.

[1000, 1001, 1002]
        ↓
    max 값 빼기
        ↓
[-2, -1, 0]
```
최대 지수값이 `exp(0)=1`이 되어 안정적으로 계산할 수 있다.
### Q3. 왜 MSE에서 오차를 제곱하는가? 
1. 양수 / 음수 오차가 상쇄되는 것을 막기위해
1. 큰 오차에 더 큰 패널티를 주기 위해
```Plain Text
오차 1 → 1
오차 2 → 4
오차 4 → 16
```
### Q4. 왜 BCE에서 clip( )이 필요한가? 
log(0)은 정의되지 않기 때문이다. 
`np.log(0.0)` #-inf 
따라서 확률 기반 BCE에서는
`safe_probs = np.clip(probabilities, eps, 1.0 - eps)` 
처럼 정확한 0, 1을 피할 수 있다. 
### Q5. 왜 정답 확률이 높으면 Cross Entropy가 작아지는가?
Cross Entropy의 샘플별 Loss는  `-log(p)` 이기때문이다.
```Plain Text
정답 확률 ↑
   ↓
log(p)가 0에 가까워짐
   ↓
-log(p) ↓
   ↓
Loss ↓
```
### Q6. 왜 Gradient를 빼는가?
Gradient는 Loss가 가장 빠르게 증가하는 방향이다 
Gradient 방향 → Loss 증가
Gradient 반대 방향 → Loss 감소
따라서 Gradient Descent에서는 `parameter -= learning_rate * gradient` 를 사용한다.
### Q7. 왜 Momentum과 Adam이 필요한가?
SGD는 현재 Gradient만 사용한다.
Momentum은 **과거 방향을 velocity에 누적**하고, 
Adam은 여기에 더해 **Gradient 크기 정보까지 저장**한다. 
```Plain Text
SGD : 현재만 봄
Momentum : 현재 + 이전 방향
Adam : 현재 + 방향 + 크기
```
따라서 세 방식은 Gradient를 사용하는 방법이 다르다. 
## 🧩 중요하게 봐야할 부분
### ⭐ 1. 학습과 추론에서 Softmax 사용을 구분하기
실제 다중 분류 학습에서 CrossEntropyLoss는 logits를 직접 입력받는 형태가 일반적이다. 
학습시 logits를 바로 안정적인 Cross Entropy에 연결하고, 추론시 Softmax를 사용한다
- 학습 → model → CrossEntropyLoss
- 추론 → model → Logits → Softmax → Probability
### ⭐ 2. BCE와 BCEWithLogitsLoss를 구분
직접 구현한 BCE
→ Probability 입력
BCEWithLogitsLoss
→ Logits 직접 이력 
> 두 함수가 기대하는 입력을 혼동하지 않아야 한다. 
### ⭐ 3. Shape 확인하기
Loss에서 자주 발생하는 오류는 값 자체보다 Shape과 정답 표현이다. 
```Plain Text
MSE
Prediction: [B] 또는 [B, 1]
Target: Prediction과 동일

BCE
Prediction: [B] 또는 [B, 1]
Target: Prediction과 동일

Cross Entropy
Logits: [B, C]
Target: [B]
```
- `B` = Batch Size
- `C` = Class 개수 
특히 Cross Entropy의 Target은 보통 클래스 인덱스 `[B]` 이다.
### ⭐ 4. Reduction도 확인하기
1. **reduction=”none”**
→ 샘별플 Loss 유지
1. **reduction=”mean”**
→ 평균 하나
1. **reduction=”sum”**
→ 합 하나 
`mean`과 `sum`은 단순 출력 차이가 아니라 Gradient 크기에도 영향을 줄 수 있으므로 배치 크기와 함께 봐야 한다. 
### ⭐ 5. Learning Rate가 너무 크거나 작은지 확인하기
- 너무 작음 → 수렴 느림
- 적잘함 → 빠르고 안정적으로 감소
- 너무 큼 → 진동 / 발산 / inf / nan 가능
Loss가 갑자기 커지거나 `nan`, `inf` 가 나타난다면 Learning Rate를 먼저 확인할 필요가 있다. 
### ⭐ 6. backward( )와 step( )을 확실히 구분하기
```Python
optimizer.zero_grad()

y_hat = model(x)

loss = criterion(y_hat, y)

loss.backward() # Gradient 계산

optimizer.step() # parameter 갱신, 계산된 Gradient로 parameter 수정
```
### ⭐ 7. 가장 중요한 전체 연결
```Python
1-1
Logits → Softmax / Log-Softmax

1-2
Loss
MSE / BCE / Cross Entropy

2-1
Gradient → Gradient Descent 

2-2 
Optimizer

```
> 즉, 1장은 모델의 출력과 틀린 정도를 계산하는 과정이고, 2장은 계산한 Loss를 실제로 줄이도록 파라미터를 학습시키는 과정으로 연결해서 이해하는 것이 가장 중요하다. 
### 📋 코드 
1-1강 코드
```Python
import numpy as np

def stable_softmax(x):
# 가장 큰 값을 빼서 exp() Overflow 방지
		shifted = x - np.max(x)
# 각 점수를 양수 값으로 반환
		exp_values = np.exp(shifted)
# 전체 합으로 나눠 확률로 변환
		Probabilities = exp_values / np.sum(exp_values)
		
		return probabilities
# 모델이 출력한 원시 점수 
logits = np.array([2.0, 1.0, -0.5])
# Logits -> Probabilities
print(stable_softmax(logits))
```
- Stable Softmax(안정적인 소프트맥스)는 딥러닝에서 컴퓨터가 계산하다가 숫자가 너무 커져서 터져버리는 현상(Overflow )를 막기 위해 사용하는 수학적 꼼수(Trick)
- np.max 또는 numpy.max는 파이썬 수학/과학 연산 라이브러리인 Numpy에서 배열 내의 최댓값을 찾아주는 함수 
> Logits → Softmax → Probability
### 1-2강 코드
```Python
import numpy as np

def mse_loss(y_pred, y_true):
		# 예측값과 정답의 차이
		errors = y_pred - y_true
		# 오차를 제곱하고 평균을 계산
		loss = np.mean(errors ** 2)
		# loss 반환
		return loss
# 실제 정답
y_true = np.array([3.0, 5.0])

# 모델 예측값
y_pred = np.array([2.0, 7.0])
# MSE 출력 
print(mse_loss(y_pred, y_true))
```
### 2-1강 코드 
```Python
# 현재 parameter 값
parameter = 1.0
# 한 번에 얼마나 이동할지 결정
learning_rate = 0.1
# Loss가 증가하는 방향
gradient = 2.0
# Gradient 반대 방향으로 parameter 갱신
parameter = parameter - learning_rate * gradient

print(parameter) # 0.8
```
> 핵심 공식 : parameter = `parameter - learning_rate x gradient` 
흐름:
예측 → Loss → Gradient → Parameter Update → 반복
### 2-2강 코드 
```Python
# 현재 parameter 값
parameter = 1.0
# 현재 Gradient 
gradient = 2.0
# 이전 이동 방향을 저장하는 값 
velocity = 0.0
# 과거 방향을 얼마나 유지할지
beta = 0.9
# 이동 크기
learning_rate = 0.1
# 이전 방향 + 현재 Gradient
velocity = beta * velocity + gradient
# velocity를 이용해 Parameter 갱신
parameter -= learning_rate * velocity

print(parameter) # 0.8
```
- Momentum은 이전 이동 방향을 velocity에 누적한다.
- Adam은 추가로 다음 정보를 저장한다.
- m = Gradient 방향의 이동 평균
- v = Gradient² 의 이동 평균
