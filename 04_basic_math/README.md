# 📐 AI를 위한 기초 수학

AI와 머신러닝, 딥러닝을 공부하기 위해 필요한 기초 수학 개념을 정리합니다.

---

# 1️⃣ 숫자와 데이터

AI에서는 숫자로 데이터를 표현합니다.

예를 들어 사람의 정보를 다음과 같이 표현할 수 있습니다.

```text
키     → 175
몸무게 → 70
나이   → 24
```

컴퓨터는 이러한 숫자 데이터를 이용하여 계산합니다.

```text
데이터
   ↓
숫자로 변환
   ↓
수학적 계산
   ↓
패턴 학습
   ↓
예측
```

---

# 2️⃣ 스칼라(Scalar)

스칼라는 하나의 숫자를 의미합니다.

```text
3
10
-5
0.25
```

예:

```python
x = 10
```

AI에서는 하나의 값도 스칼라로 표현할 수 있습니다.

예:

```text
온도 = 25
점수 = 90
가격 = 10000
```

---

# 3️⃣ 벡터(Vector)

벡터는 여러 개의 숫자를 하나로 묶은 것입니다.

```text
[1, 2, 3]
```

예를 들어 학생의 정보를 벡터로 표현할 수 있습니다.

```text
[
 키,
 몸무게,
 나이
]
```

실제 값:

```text
[175, 70, 24]
```

NumPy에서는 다음과 같이 표현합니다.

```python
import numpy as np

x = np.array([175, 70, 24])

print(x)
```

---

# 4️⃣ 행렬(Matrix)

행렬은 여러 개의 벡터를 모은 것입니다.

```text
[
 [1, 2],
 [3, 4]
]
```

예:

```python
import numpy as np

A = np.array([
    [1, 2],
    [3, 4]
])

print(A)
```

행렬 구조:

```text
1  2
3  4
```

이 행렬은:

```text
2개의 행
2개의 열
```

을 가지고 있습니다.

---

# 5️⃣ 텐서(Tensor)

텐서는 스칼라, 벡터, 행렬을 더 높은 차원으로 확장한 개념입니다.

```text
스칼라
↓
3

벡터
↓
[1, 2, 3]

행렬
↓
[
 [1, 2],
 [3, 4]
]

텐서
↓
여러 개의 행렬
```

딥러닝에서는 데이터를 대부분 텐서 형태로 다룹니다.

예를 들어 이미지 데이터:

```text
이미지 1장
↓
행렬

여러 장의 이미지
↓
텐서
```

PyTorch에서는:

```python
import torch

x = torch.tensor([
    [1, 2],
    [3, 4]
])

print(x)
```

# 6️⃣ 벡터 연산

## 벡터 덧셈

```text
[1, 2, 3]
+
[4, 5, 6]
```

결과:

```text
[5, 7, 9]
```

같은 위치의 숫자끼리 계산합니다.

```text
1 + 4 = 5
2 + 5 = 7
3 + 6 = 9
```

NumPy:

```python
import numpy as np

a = np.array([1, 2, 3])
b = np.array([4, 5, 6])

print(a + b)
```

출력:

```text
[5 7 9]
```

벡터에 하나의 숫자를 곱할 수 있습니다.

```text
2 × [1, 2, 3]
```

결과:

```text
[2, 4, 6]
```

NumPy:

```python
import numpy as np

x = np.array([1, 2, 3])
```

출력:

```text
[2 4 6]
```

# 8️⃣ 행렬 곱

행렬끼리 곱할 수 있습니다.

```text
A
=
[
 [1, 2],
 [3, 4]
]

B
=
[
 [5, 6],
 [7, 8]
]
```

NumPy:

```python
import numpy as np

A = np.array([
    [1, 2],
    [3, 4]
])

B = np.array([
    [5, 6],
    [7, 8]
])

result = A @ B

print(result)
```

출력:

```text
[[19 22]
 [43 50]]
```

행렬 곱은 AI와 딥러닝에서 매우 중요합니다.

신경망에서는 다음과 같은 계산이 반복됩니다.

```text
입력 데이터
    ↓
행렬 곱
    ↓
가중치 적용
    ↓
활성화 함수
    ↓
다음 층
```

# 9️⃣ 함수(Function)

함수는 입력값을 받아서 결과를 반환하는 규칙입니다.

예:

```text
f(x) = x + 1
```

만약:

```text
x = 3
```

이면:

```text
f(3) = 4
```

Python:

```python
def f(x):
    return x + 1

print(f(3))
```

출력:

```text
4
```

---

# 🔟 선형 함수

대표적인 선형 함수는 다음과 같습니다.

```text
y = wx + b
```

여기서:

```text
x → 입력값
w → 가중치
b → 편향
y → 출력값
```

예:

```text
y = 2x + 1
```

만약:

```text
x = 3
```

이면:

```text
y = 2 × 3 + 1
y = 7
```

Python:

```python
x = 3

w = 2
b = 1

y = w * x + b

print(y)
```

출력:

```text
7
```

이 구조는 머신러닝과 딥러닝의 기본 구조와 연결됩니다.

```text
입력값 x
   ↓
가중치 w
   ↓
편향 b
   ↓
출력값 y
```

---

# 1️⃣1️⃣ 기울기(Slope)

기울기는 값이 얼마나 변하는지를 나타냅니다.

예:

```text
y = 2x
```

x가 1 증가할 때 y는 2 증가합니다.

```text
x = 1 → y = 2
x = 2 → y = 4
x = 3 → y = 6
```

따라서 기울기는:

```text
2
```

입니다.

---

# 1️⃣2️⃣ 미분(Differentiation)

미분은 함수의 변화량을 계산하는 방법입니다.

쉽게 말하면:

```text
입력이 조금 변했을 때
출력이 얼마나 변하는가?
```

를 계산합니다.

예:

```text
y = x²
```

미분하면:

```text
y' = 2x
```

예를 들어:

```text
x = 3
```

이면:

```text
2 × 3 = 6
```

이 값은 해당 위치에서의 변화율을 의미합니다.

---

# 1️⃣3️⃣ 편미분(Partial Differentiation)

여러 개의 변수가 있을 때 특정 변수에 대해서만 미분하는 것을 편미분이라고 합니다.

예:

```text
f(x, y) = x² + y²
```

x에 대해서 미분:

```text
∂f/∂x = 2x
```

y에 대해서 미분:

```text
∂f/∂y = 2y
```

머신러닝에서는 여러 개의 가중치가 있기 때문에 편미분 개념이 사용됩니다.

---

# 1️⃣4️⃣ 손실 함수(Loss Function)

손실 함수는 모델의 예측이 실제 정답과 얼마나 차이나는지 계산합니다.

```text
예측값
   ↓
손실 함수
   ↓
정답과 비교
   ↓
오차 계산
```

예:

```text
정답 = 10
예측 = 8
```

오차:

```text
10 - 8 = 2
```

대표적인 손실 함수 중 하나는 평균 제곱 오차입니다.

```text
MSE = 평균((예측값 - 실제값)²)
```

Python:

```python
y_true = 10
y_pred = 8

loss = (y_true - y_pred) ** 2

print(loss)
```

출력:

```text
4
```

---

# 1️⃣5️⃣ 평균(Mean)

평균은 데이터의 대표값을 구하는 방법입니다.

예:

```text
[1, 2, 3, 4, 5]
```

평균:

```text
(1 + 2 + 3 + 4 + 5) / 5
```

결과:

```text
3
```

NumPy:

```python
import numpy as np

x = np.array([1, 2, 3, 4, 5])

print(np.mean(x))
```

출력:

```text
3.0
```

---

# 1️⃣6️⃣ 확률(Probability)

확률은 어떤 사건이 발생할 가능성을 나타냅니다.

범위:

```text
0 ≤ 확률 ≤ 1
```

예:

```text
0 → 발생하지 않음
0.5 → 50% 확률
1 → 반드시 발생
```

딥러닝의 분류 문제에서는 모델의 출력값을 확률처럼 해석하기도 합니다.

예:

```text
고양이 → 0.8
강아지 → 0.2
```

# 1️⃣7️⃣ 활성화 함수

신경망에서는 계산 결과를 그대로 사용하지 않고 활성화 함수를 적용합니다.

```text
입력
 ↓
선형 계산
 ↓
활성화 함수
 ↓
출력
```

대표적인 활성화 함수:

```text
ReLU
Sigmoid
Softmax
```

---

## ReLU

ReLU는 음수를 0으로 바꿉니다.

```text
f(x) = max(0, x)
```

예:

```text
입력:  [-2, -1, 0, 1, 2]

출력: [0, 0, 0, 1, 2]
```

PyTorch:

```python
import torch
import torch.nn as nn

relu = nn.ReLU()

x = torch.tensor([-2.0, -1.0, 0.0, 1.0, 2.0])

print(relu(x))
```

출력:

```text
tensor([0., 0., 0., 1., 2.])
```

# 1️⃣8️⃣ Softmax

Softmax는 여러 개의 값을 확률 형태로 변환합니다.

예:

```text
[2.0, 1.0, 0.1]
```

↓

```text
[0.66, 0.24, 0.10]
```

특징:

```text
모든 값의 합 = 1
```

주로 여러 개의 클래스를 분류할 때 사용합니다.

예:

```text
고양이 → 0.7
강아지 → 0.2
토끼   → 0.1
```

# 1️⃣9️⃣ 경사하강법(Gradient Descent)

경사하강법은 손실을 줄이는 방향으로 가중치를 수정하는 방법입니다.

```text
현재 가중치
      ↓
예측
      ↓
손실 계산
      ↓
기울기 계산
      ↓
가중치 수정
      ↓
다시 예측
```

수식:

```text
새로운 가중치

w = w - 학습률 × 기울기
```

학습률은 한 번에 얼마나 이동할지를 결정합니다.

```text
학습률이 너무 크다
→ 최적값을 지나칠 수 있음

학습률이 너무 작다
→ 학습 속도가 느림
```
