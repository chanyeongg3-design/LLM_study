# 🧪 Project 1 - 2026-09-16 · KANT 모델 비교

## 1. 오늘의 목표

동일한 Python 백엔드 버그 10문제를 대상으로 Local LLM인 `qwen2.5-coder:7b-instruct`와 Cloud LLM인 `gpt-5.6-luna`의 문제 해결 성능을 비교한다.

특히 Public Test와 Hidden Test에서 나타나는 차이를 확인하고, 실패 원인을 분석한다.

> 이번 Cloud 결과는 탐색용 결과이며, 팀 공식 프로토콜은 `5문제 × 1회`이다.

## 2. 실험 / 작업 조건

| 항목 | 내용 |
| --- | --- |
| 모델 / 기술 | `qwen2.5-coder:7b-instruct` / `gpt-5.6-luna` / Ollama / OpenAI 호환 API / pytest |
| 데이터 | Python 백엔드 버그 문제 `B01~B10`, Public Test, Hidden Test |
| 실행 환경 | Qwen: RTX 5060 Laptop, 평균 VRAM 4,756 MiB / Luna: 원격 서버 |
| 실행 횟수 | 모델별 10문제 × 2회 = 20회, 총 40회 |
| 주요 설정 | Qwen: Temperature 0.2, Seed 42·43 / Luna: Temperature·Seed 제어 불가 |

문제, 프롬프트, 테스트, 채점 로직은 동일하게 유지했다.

## 3. 오늘 진행한 작업

- 두 모델에 동일한 문제와 프롬프트를 입력해 결과를 생성했다.
- 동일한 Public Test와 Hidden Test로 생성 코드를 채점했다.
- 프롬프트, 테스트 스위트, 채점기 해시가 동일한지 확인했다.
- 모델별 정확도, 응답 시간, 출력 토큰과 실패 유형을 비교했다.
- Qwen의 Hidden Test 실패 로그를 분석했다.

## 4. 결과

| 지표 | Qwen | Luna |
| --- | ---: | ---: |
| Accuracy | 30% | 100% |
| 성공 / 실패 | 6 / 14 | 20 / 0 |
| 평균 응답 시간 | 2.225초 | 4.845초 |
| 출력 토큰 | 2,683 | 6,567 |
| 형식 오류 | 0 | 0 |
| 호출 실패 | 0 | 0 |

응답 시간은 Local GPU 추론과 Cloud 네트워크 호출이라는 실행 환경 차이가 있으므로 직접적인 속도 비교에는 한계가 있다.

## 5. 문제 / 실패 원인

- 발생한 문제: Qwen은 20회 중 14회 실패했고, 특히 Hidden Test에서 실패가 많았다.
- 원인: 입력값 검증, `ValueError` 처리, 입력 데이터 불변성, `None`·`False`·누락값 구분, 재시도, 예외 처리, Rollback과 Atomicity 같은 세부 명세 처리가 부족했다.
- 해결 여부: 실패 원인은 확인했지만 모델이나 프롬프트 개선 실험은 아직 진행하지 않았다.
- 추가로 확인할 내용: B09는 테스트 10개 중 9개를 통과했지만 Hidden Test 1개 실패로 최종 실패 처리됐다. 유사한 경계 조건을 자동 분류할 방법을 확인해야 한다.

## 6. 결과 분석

이번 조건에서 Qwen은 30%, Luna는 100%를 기록해 70%p 차이가 발생했다.

- 잘된 부분: 두 모델 모두 형식 오류와 호출 실패 없이 Python 코드를 생성했다.
- 부족했던 부분: Qwen은 공개된 예제는 일부 해결했지만 Hidden Test가 요구하는 예외 처리와 상태 보존 조건을 충분히 반영하지 못했다.
- 모델 / 방법 간 차이: Qwen은 Local 환경에서 샘플링 설정을 고정할 수 있었고, Luna는 설정 통제가 제한적이지만 세부 명세 처리에서 더 높은 성공률을 보였다.
- 결과를 해석할 때 주의할 점: Luna의 Temperature와 Seed를 고정하지 못했고, 이번 실험은 공식 Cloud 프로토콜이 아니므로 결과를 전체 모델 성능으로 일반화하면 안 된다.

## 7. 오늘 배운 개념

- **Hidden Test**: 모델에게 공개하지 않고 예외 상황과 세부 요구사항을 평가하는 테스트
- **Immutability**: 함수나 작업이 입력값을 직접 변경하지 않는 성질
- **Idempotency**: 같은 요청을 반복해도 결과가 동일한 성질
- **Atomicity**: 작업이 전부 성공하거나 전부 취소되는 성질
- **Rollback**: 작업 실패 시 변경 사항을 이전 상태로 되돌리는 처리
- **Reproducibility**: 같은 조건에서 실험 결과를 다시 재현할 수 있는 성질
