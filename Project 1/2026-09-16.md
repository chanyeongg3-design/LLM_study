# 🧪 Project 1 - 2026-09-16 · KANT 모델 비교

## 1. 실험 목적

동일한 Python 백엔드 버그 10문제를 대상으로 `qwen2.5-coder:7b-instruct`(Local)와 `gpt-5.6-luna`(Cloud)의 문제 해결 성능을 비교했다.
※ 이번 Cloud 결과는 **탐색용 결과**이며, 팀 공식 프로토콜은 `10 문제 × 2회`이다.

## 2. 비교 조건

| 항목 | Qwen | Luna |
| --- | --- | --- |
| 실행 위치 | RTX 5060 Laptop | 원격 서버 |
| 실행 횟수 | 10문제 × 2회 | 10문제 × 2회 |
| Temperature | 0.2 | 제어 불가 |
| Seed | 42 / 43 | 제어 불가 |
| VRAM | 4,756 MiB | 해당 없음 |

문제, 프롬프트, 테스트, 채점기는 동일하게 사용했다.

## 4. Qwen 주요 실패 원인

- 입력값 검증 및 `ValueError` 처리
- 입력 데이터 불변성
- `None`, `False`, 누락값 구분
- 재시도 및 예외 처리
- Rollback / Atomicity 처리

B09는 테스트 10개 중 9개를 통과했지만 Hidden Test 1개 실패로 최종 실패 처리됐다.

## 5. 결과 분석

이번 조건에서는 Qwen 30%, Luna 100%로 **70%p 차이**가 발생했다.
특히 Qwen은 Public Test보다 Hidden Test에서 많이 실패했다. 즉 핵심 차이는 **눈에 보이는 예제를 해결하는 능력보다, 예외·불변성·Rollback 같은 숨은 명세까지 처리하는 능력**이었다.
다만 Luna는 Temperature와 Seed를 고정하지 못했고, 이번 실험도 공식 Cloud 프로토콜이 아니므로 결과를 전체 모델 성능으로 일반화하면 안 된다.

## 6. 오늘 배운 개념

- **Hidden Test**: 모델에게 보이지 않는 평가 테스트
- **Immutability**: 입력값을 변경하지 않는 성질
- **Idempotency**: 같은 요청을 반복해도 결과가 동일한 성질
- **Atomicity**: 작업이 전부 성공하거나 전부 취소되는 성질
- **Rollback**: 실패 시 이전 상태로 복구
- **Reproducibility**: 같은 조건에서 결과를 다시 재현하는 것
